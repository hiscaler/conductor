# 聊天结果模板（默认）

本模板用于正式任务完成后的默认聊天展示。它只展示本轮相关结果，完整生产记录仍按 `templates/production-output.md` 生成并保存。

以下场景不使用本模板：

- 启动菜单、最低输入采集、商品资料示例和创意方向菜单。
- 用户选择“从选品到上架走完整流程”。
- 用户要求生成完整上架包。
- 用户要求上架前 QA 或完整验收。
- 用户明确要求“完整报告”“完整 16 章”或“按完整模板输出”。

上述需要完整展示的场景，聊天直接使用 `templates/production-output.md`。

输出规则：

- 保留下面 5 个章节，章节内只展示本轮实际相关内容。
- 不得展开与当前任务无关的章节，也不列出大段“本轮未执行”。
- 买家可见文案使用目标市场语言；状态、说明、风险和动作使用中文。
- 文案任务直接给出可复制的最终文案；图片或视频任务列出应生成数量、实际数量、完成状态和文件路径。
- 缺失事实、访问限制和未完成产物必须明确列出。
- 正式执行生成的完整报告实际版本路径必须显示；启动交互和纯查看任务可写“不适用”。
- 完整报告文件名固定为 `上架/完整生产报告.md`；首次生产填写基础 Listing 目录中的路径，再次生产填写 `{Listing标识}-v2/`、`-v3/` 等版本目录中的实际路径。
- 下一步动作只保留 1-5 个本轮明确任务范围内的数字选项；不得因为完整报告存在未执行章节而推荐扩展任务。

- 完整报告状态：已生成 / 未生成 / 不适用

## 2. 本轮产出

按当前任务展示实际结果，例如：

- 文案：标题、描述、要点、关键词或广告文案。
- 图片：套图脚本、提示词、应生成数量、实际独立文件数量、缺失图型、图片路径和验收结论。
- 视频：脚本、分镜、字幕/口播、生成路径和验收结论。
- 研究：选品结论、竞品证据、供应商候选、利润测算或合规结论。

不得显示与当前任务无关的内容类型。

## 3. 缺失与风险

- 缺失项：
- 风险：
- 需要人工确认：

没有缺失或风险时写“无”，不得删除字段。

## 4. 已保存文件

| 产物 | 路径 | 状态 |

| 完整生产报告 | 填写本轮实际保存路径 | 已生成 / 未生成 / 不适用 |

只追加本轮实际生成或更新的文件，不列出不存在的文件。

## 5. 下一步动作

先用一句话说明推荐原因，再提供 1-5 个本轮任务范围内的数字动作。只有 1 个合理动作时只显示 1 个，不得为了凑数量加入未请求的任务。环境支持选择器时优先弹出选择器；不支持时使用：

```text
请选择下一步动作：
1. ...
2. ...
```
