# Agent 测试与验收

本文件用于测试 Conductor Agent 是否命中项目规则。普通使用时，优先在 Codex 中输入“你好”走启动向导，不需要手写 `请按 templates/production-output.md 强制格式输出`。

## 测试目标

- 验证新窗口是否正确加载项目规则。
- 验证输出是否严格使用 `templates/production-output.md`。
- 验证启动向导、趋势找品、目标市场数据源、文案、图片、视频和下一步动作是否按规则执行。
- 验证失败时是否明确写出缺失信息、未获取数据和未完成状态。

## 趋势找品测试

```text
请按 templates/production-output.md 强制格式输出。

我现在只有方向，还没有确定具体商品。

方向：Pilates / That Girl / Morning Routine
目标市场：美国
目标平台：待定
要求：
1. 先使用趋势筛选判断这个方向是否值得继续看。
2. 再参考 YouTube、TikTok、Instagram 等短视频场景，提取视频或内容中反复出现的商品机会。
3. 判断每个候选商品是否有品牌真空、供应链可行性、平台适配度和内容传播性。
4. 输出候选商品评分，并告诉我优先验证哪 3 个商品。
5. 如果无法读取某个平台的数据，请明确写“未获取”或“受访问限制”，不要编造播放量、评论、增长率、销量或排名。

本轮只做找品和选品判断，不生成文案、套图或视频。
```

检查重点：

- 是否根据目标国家选择数据源，而不是默认套用美国/Google。
- 是否先进入 `trend-and-video-discovery-agent`，而不是直接生成标题、描述或图片。
- 是否区分趋势信号、短视频场景信号和推断假设。
- 是否输出候选商品清单、品牌真空判断和 100 分评分。
- 是否把无法获取的数据明确标注为“未获取”或“受访问限制”。
- 是否提供 2-3 个目标平台热销参考链接；无法获取时是否标注“未获取”或“受访问限制”，且没有用相近平台链接替代目标平台结论。
- 是否输出 1688、Alibaba、义乌购等可访问供应链平台的候选供应商查询状态；无法获取时是否标注访问限制。
- 供应链报价是否包含店铺名称、商品/店铺网址、价格区间、MOQ 或起订条件、抓取日期和获取状态；只有泛化价格区间时，是否判定为无效参考而不是采购价结论。
- 平台需要登录时，是否只要求用户完成登录/验证码，而不是要求用户自行筛选或打开 3-5 个候选页面；Agent 是否继续执行搜索、筛选、打开详情页和提取数据。
- 下一步执行清单是否包含“补充竞品调研”“供应链验证”“选择候选商品进入上架产出”等动作。

## 非美国市场测试

```text
请按 templates/production-output.md 强制格式输出。

我现在只有方向，还没有确定具体商品。

方向：居家咖啡角 / Home Coffee Bar
目标市场：日本
目标平台：待定
要求：
1. 先选择适合日本市场的趋势、内容和电商验证数据源。
2. 生成日语关键词，并保留英文对照关键词。
3. 再做趋势筛选、短视频场景验证和候选商品评分。
4. 不能只用美国市场数据或英文关键词下结论。
5. 如果无法读取 Yahoo Japan、Rakuten、Amazon JP、YouTube 或 TikTok 数据，请明确写“未获取”或“受访问限制”。

本轮只做找品和选品判断，不生成文案、套图或视频。
```

检查重点：

- 是否根据日本市场选择数据源。
- 是否生成日语关键词和英文对照关键词。
- 是否没有把美国市场数据当作日本市场结论。
- 无法访问的数据源是否标注为“未获取”或“受访问限制”。

## 已有产品直接产出测试

```text
请按 templates/production-output.md 强制格式输出。

我已经有产品了，不需要完整选品流程。

产品名称：可定制文字、图片 11oz 白色马克杯
产品类目：水杯
目标平台：Temu
目标市场：美国
核心功能：喝咖啡、补水
产品类型：定制类
销售单位/组合形态：单件
包含内容：1 个 11oz 白色陶瓷马克杯
销售数量：1
是否同款/混色/混款：同款
定制内容：文字、图片
定制位置：杯身外侧
定制示例素材池：Emma / Olivia / Mom / Best Dad / Coffee Time / Morning Brew / 通用风景照片 / 花朵图案 / 几何图案 / 宠物剪影
定制素材版权规则：只使用通用非侵权示例；可能涉及版权、商标或肖像权的素材默认不使用
规格参数：容量 11oz，高度 9.5 cm，杯口直径 8.2 cm，底径 7.5 cm，含把手宽度 12 cm
材质：陶瓷
供货状态：已有供应商

请直接输出 Temu 标题、描述、关键词，并生成一套适合 Temu 的 AI 商品图。同时保留每张图的脚本、提示词和生成路径。
请保存图片路径，并在下一步执行清单中提供“保存文案资产”“做上架前 QA”“生成视频脚本”“生成主视频”等可执行动作。
```

检查重点：

- 是否出现 `production-output.md` 的 16 个章节。如果没有，说明当前测试窗口没有命中指挥家 Agent 或没有加载本项目模板。
- 商品标题、描述、关键词是否为英文。
- 图片数量是否覆盖完整套图，而不是只生成 3-4 张。
- 销售单位/组合形态是否被正确识别；如果是对装、多件装或套装，标题、主图、包装图、包装清单和价格判断是否展示实际售卖数量。
- 每张商品图是否是独立文件；单张拼图、九宫格或带多个缩略图的预览图不算整套图。
- `生成图片路径` 和 `图片验收报告` 是否写出应生成图片数、实际独立图片文件数、缺失图片类型和整套图状态。
- Temu 定制类商品是否包含最终定制主图、到手内容/包装图、定制操作示意图、尺寸规格图、细节放大图、生活场景图、定制效果示例图、卖点集合图。
- 尺寸规格图的画面里是否直接同时标注 `cm` 和 `inch`，只在脚本写 `inch` 但图片里没有不算通过。
- 场景图、包装图、卖点图是否有基于事实的简短英文文案；不能只是无文字图片，也不能写未确认功能，例如保温、保冷、防漏。
- 主图、包装图和定制效果图是否使用真实感样例内容，而不是 `YOUR NAME`、`YOUR TEXT`、`CUSTOM PHOTO` 这类占位词。
- 随机搭配后的定制效果是否贴合实际商品，文字和图片风格是否一致，是否自然贴合杯身弧面。
- 定制素材是否避开品牌 logo、商标、影视/动漫/游戏角色、球队标志、名人肖像、真实人物照片、艺术家作品、摄影作品等版权或肖像权风险；这些素材默认不使用，不要求用户确认。
- 如果只生成 4 张或缺少必备图，图片验收报告是否判定为“未完成”。

## 销售单位识别测试

```text
请按 templates/production-output.md 强制格式输出。

我已经有产品了，不需要完整选品流程。

产品名称：5 个装 11oz 白色陶瓷马克杯
产品类目：水杯
目标平台：Temu
目标市场：美国
核心功能：喝咖啡、喝茶、日常饮水
产品类型：普货
销售单位/组合形态：多件装
包含内容：5 个同款 11oz 白色陶瓷马克杯
销售数量：5
是否同款/混色/混款：同款
规格参数：容量 11oz，高度待确认，杯口直径待确认，底径待确认
材质：陶瓷
供货状态：已有供应商

请直接输出 Temu 标题、描述、关键词，并生成一套适合 Temu 的 AI 商品图。
```

检查重点：

- 标题是否使用 `5-Pack`、`Set of 5` 等英文多件装表达，而不是只写单个 mug。
- `5 个装` 只是测试样例；规则必须适用于任意数量，例如 `3个装`、`3 个装`、`三个装`、`３个装`、`3 件装`、`三件装`、`3-pack`、`pack of 3`、`set of 3` 都应被识别为销售数量 3 的多件装。
- 商品描述、包装清单和价格策略是否同时说明整套 5 个和单件折算价。
- 主图、到手内容图和包装图是否展示 5 个杯子，而不是只展示 1 个杯子。
- 如果用户写“N 件套”但没有说明是 N 个同款还是主商品加配件，是否标记为“待确认”并避免生成误导性主图。

## 常见失败表现

- 输出仍是自由格式，例如只出现“Temu 标题 / 商品描述 / 关键词 / AI 商品图”。
- 没有 `## 1. 输入摘要` 到 `## 16. 下一步执行清单`。
- 目标市场为美国，但买家侧标题、描述、关键词仍使用中文。
- 任意平台的卖家侧内容出现整段英文，包括英文栏目名、策略说明、事实清单、待确认项、风险提示、合规说明、验收报告或下一步动作。允许使用目标市场语言的范围仅限可直接复制到平台、面向买家或用于搜索及广告投放的最终文案值。
- 把无声视频、只有背景音乐没有目标市场语言口播的视频、没有烧录字幕的视频，或多张静态商品图加转场/推拉/平移形成的幻灯片视频标记为“已完成”。
- 视频字幕使用背景条、色块、气泡、卡片或半透明底，而不是纯文字叠加。
- 用户没有指定视频场景时，未读取预设场景库、未记录自动选择的预设名称和理由，或没有记录素材来源与镜头映射。
- 因用户没有提供实拍视频或供应商视频而阻塞视频生成；默认应根据平台、品类、商品参考图、已生成商品图和产品资料自动生成动态视频。
- 所有产品机械套用同一条“展示—卖点—下单”流程，未分别选择广告故事、镜头风格和产品动作，或视频没有形成“钩子—故事—体验—结果—行动提示”的完整广告叙事。
- 镜头之间仅使用淡入淡出、闪白、推拉或缩放等模板转场，没有动作匹配或合理连续状态，导致视频明显生硬。
- 口播全程使用相同语速、音高、音量和句尾语气，逐字照读字幕、卖点或参数，没有与广告故事匹配的情绪变化、自然停顿和重音。
- Temu 视频使用 `9:16` 或其他非 `1:1`、`3:4`、`16:9` 比例，时长超过 `60 秒`，文件超过 `100 MB`，没有清晰商品主体或核心卖点，或出现 PPT/静态幻灯片、黑边、水印。
- 声称已生成整套图，但实际只有 1-4 张。
- 把单张拼图、九宫格或缩略图预览当作整套图。
- 尺寸图只标注 `cm`，没有 `inch`。
- 图片验收报告没有列出缺失图片类型。
- 使用 `YOUR NAME`、`YOUR TEXT`、`CUSTOM PHOTO` 作为最终商品图案。

如果出现以上问题，优先判断为测试入口没有加载项目规则，或当前输出没有按 `AGENTS.md` 和 `templates/production-output.md` 执行。
