# 启动向导

启动向导用于用户刚打开 Conductor 项目、还不知道怎么提问时，引导用户用数字选择当前业务场景。

启动向导和 `action-menu.md` 分工不同：

- 启动向导：任务开始前选择流程。
- 下一步动作菜单：一次产出完成后继续推进任务。

## 触发词

当用户只输入以下短句，或明显是在询问“怎么开始”时，必须进入启动向导：

- 你好
- hello
- 开始
- 菜单
- 帮助
- 使用说明
- 我要用指挥家
- 我该怎么用
- 可以做什么

匹配入口词时去除首尾空格，英文字母不区分大小写。

触发启动向导时，不输出 `templates/production-output.md` 的 16 个章节。启动向导本身是入口菜单，不是正式生产产出。

## 展示规则

- 流程选择必须使用纯数字。
- 不使用 `A1`、`B2`、`P1` 这类字母编号。
- 支持单选，例如 `2`。
- 支持组合选择，例如 `2,7`。
- 展示 10-14 个高频场景即可，不要一次展开全部文档。
- 每个选项用一句话说明结果，避免长篇解释。
- 用户选择后，不要立即执行正式产出；先根据所选任务判断最低必要输入，只询问当前缺失的信息。不得对每个菜单统一索取商品名称或商品图片，也不得默认抛出完整产品档案让用户填写。

## 启动菜单

```text
你好，欢迎使用  Conductor。请选择你现在的场景：

1. 我已经有产品了，只想生成标题、描述、关键词
2. 我已经有产品了，想生成文案 + AI 商品图
3. 我已经有产品了，想生成文案 + AI 商品图 + 视频脚本
4. 我只有方向或想法，还没有确定具体产品
5. 我有一个产品想法，想判断是否值得做
6. 我有产品，但不确定适合哪个平台
7. 我有竞品链接，想做竞品分析
8. 我只想生成一套商品图
9. 我只想生成视频脚本或短视频
10. 我已经有 listing 草稿，想做上架前 QA
11. 我已经上架了，想做数据复盘和优化
12. 我想保存产物或查看输出目录
13. 我想从选品到上架走完整流程

请输入数字，例如：2
也可以组合输入，例如：2,7
```

## 数字选择处理

当用户在启动向导之后回复纯数字时，指挥家必须按最近一次启动菜单解释该数字。

如果当前上下文最近一次展示的是“下一步执行清单”，则数字按 `action-menu.md` 解释；如果最近一次展示的是启动向导，则数字按本文件解释。

如果用户输入多个数字：

- 先合并场景需求。
- 去掉重复阶段。
- 合并各任务的最低必要输入，只询问一次；不得输出重复问题或默认展示完整填写模板。
- 不要要求用户再次解释数字含义。

## 选择后的动态采集

用户选择菜单后，按任务分流：

| 任务类型 | 商品名称 | 商品图片 | 最低必要输入 |
| --- | --- | --- | --- |
| 找品、趋势筛选 | 不需要 | 不需要 | 目标市场、品类方向/人群/关键词；目标平台可待定 |
| 判断产品是否值得做、平台匹配 | 建议提供 | 选填 | 产品名称或想法、目标市场、已知成本/售价（可选） |
| 文案与关键词 | 必填或提供可匹配 SKU | 选填 | 商品名称或 SKU、目标平台、目标市场；已有事实或链接可选 |
| 商品图片、商品视频、完整上架资产 | 必填或提供可匹配 SKU | 原则上必填 | 商品名称或 SKU、目标平台、目标市场，以及图库主图/商品图/商品链接/充分外观资料四者之一 |
| 竞品分析 | 自有商品可选 | 可选 | 竞品链接、榜单入口、平台关键词或截图至少一种 |
| 合规检查、上架 QA | 不一定 | 按检查对象决定 | 待检查内容、链接、文件或产出路径 |
| 数据复盘 | 必填或已有任务可复用 | 不需要 | 上架时间和运营数据 |
| 保存/查看产物、帮助 | 不需要重复提供 | 不需要 | 产出路径、产品标识或帮助主题 |

执行要求：

- 复用本会话已经提供的商品名称、图片、平台、市场和规格，只追问缺失项。
- 用户只提供商品名称时，可以先生成低置信度参考示例；图片/视频生产前仍需取得可靠外观依据。
- 收到最低必要输入后，系统直接自动识别商品，并研究目标平台同类商品、热销榜、商品详情页和可访问评论；不要再向用户追问核心功能、卖点、购买动机、使用场景、目标人群或定制示例。
- 系统结合商品本身、评论痛点和目标市场仍可执行的未来节日，自动生成“核心功能、希望突出卖点、主要购买动机、定制示例”。
- 已经过期、来不及生产运输或与商品无关的节日不得进入示例。
- 无法访问评论或榜单时简短说明“未获取”，继续使用已有证据生成，不把研究过程变成长表格要求用户处理。
- 竞品常见但自身商品无法确认的功能只能标记“待确认”，不得直接写入最终买家文案。
- 用户可直接输入商品名称、单个 SKU 或 SKU 组合。系统先按忽略大小写、去除首尾空格后的 SKU 精确匹配，再按商品名称和相似商品处理；多个 SKU 始终组成一个 listing，未写数量默认 1，相同 SKU 自动合并数量。

### 最小交互示例

用户选择需要具体商品的任务后，必须提供一段带真实示例值、可直接复制修改的输入模板，不能只列出字段名称或把空字段预填到输入框。商品图片通过附件上传，不要求用户在文本中填写图片路径。

请复制代码块里的内容，修改后回传，并同时上传至少一张能看清商品外观的图片：

```text
商品或SKU：MUG0110RD
目标平台：Temu
目标市场：美国

商品链接：https://...（如果暂时没有图片，可填写可靠商品链接）
```

组合销售时，将第一行改为 `商品或SKU：MUG0110RD * 2, MUG0110WH * 1`。

文案任务应说明图片为建议提供；图片、视频和完整上架资产任务应说明商品图片、可靠商品链接或充分外观资料至少提供一种。

请求用户回传最低必要输入时，必须在可复制代码块外说明后续顺序，不能写成“确认商品资料后直接输出文案/图片/视频”。内容生产任务统一表达为：

```text
收到后，我会先匹配商品资料并生成可复制的完整商品示例。你修改并回传商品资料后，我会先生成具体创意方向；存在多个可执行方向时，会提供 3-5 个方向供你输入数字选择，如需系统自动选择请输入 0。创意确定后，再按所选任务正式生成文案、图片或视频。
```

最后一句必须根据当前任务替换成具体产物。例如只做文案时写“创意确定后，再生成标题、要点描述、长描述和关键词”；不得笼统写成与当前任务无关的全部产物。

用户选择“趋势找品”后，只需提示：

请复制代码块里的内容，按当前方向修改后回传：

```text
目标市场：美国
感兴趣的品类/人群/关键词：宠物出行用品
目标平台：待定
成本、售价或不想做的类目（选填）：首批小批量测试，不做高认证风险产品
```

## 用户回传示例后的创意方向选择

用户回传商品资料后，如果本轮任务包含文案、图片、视频或完整上架资产，必须先按 [创意方向选择流程](./creative-direction-selection.md) 形成创意策略，并判断是否需要展示创意方向菜单。

触发时只输出 3-5 个纯数字创意方向，不输出 `templates/production-output.md` 的 16 个章节。用户输入对应创意编号进行选择；输入 `0` 表示系统自动选择。选择完成后，指挥家生成可执行创意方案，并继续执行原菜单任务。

如果用户明确要求“跳过创意选择”或“直接按默认输出”，则不展示菜单，由系统形成事实优先的默认创意策略；用户已给出明确方向时沿用该方向。只有本轮任务只涉及供应链、合规、QA、保存或查看产物时，创意策略写“不适用”。处理结果都必须记录在完整生产报告第 6 节。

示例：

- `2,7` = 已有产品 + 竞品分析 + 文案 + AI 商品图。
- `4,9` = 只有方向 + 趋势找品 + 视频脚本方向。
- `3,10` = 已有产品 + 文案 + 图片 + 视频脚本 + 上架前 QA。

## 执行完成后的继续菜单

正式产出完成后，聊天默认按 `templates/chat-output.md` 只展示本轮相关结果。完整 16 章报告文件名固定为 `上架/完整生产报告.md`；首次生产使用基础 Listing 目录，再次生产时整批进入 `{Listing标识}-v2/`、`-v3/`。选择第 13 项完整流程、生成完整上架包、执行上架前 QA/完整验收，或用户明确要求完整报告时，聊天直接展开完整报告。

随后不再展示完整启动菜单。全部菜单都必须根据原启动范围和当前产出状态展示 1-5 个相关动作；宁可只展示 1 个，也不得加入其他菜单或用户未请求的扩展任务。规则见 [action-menu](./action-menu.md)。
