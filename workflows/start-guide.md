# 启动向导

启动向导用于用户刚打开 Conductor 项目、还不知道怎么提问时，引导用户用数字选择当前业务场景。

启动向导和 `action-menu.md` 分工不同：

- 启动向导：任务开始前选择流程。
- 下一步动作菜单：一次产出完成后继续推进任务。

## 触发词

当用户只输入以下短句，或明显是在询问“怎么开始”时，必须进入启动向导：

- 你好
- 开始
- 菜单
- 帮助
- 使用说明
- 我要用指挥家
- 我该怎么用
- 可以做什么

触发启动向导时，不输出 `templates/production-output.md` 的 16 个章节。启动向导本身是入口菜单，不是正式生产产出。

## 展示规则

- 流程选择必须使用纯数字。
- 不使用 `A1`、`B2`、`P1` 这类字母编号。
- 支持单选，例如 `2`。
- 支持组合选择，例如 `2,7`。
- 展示 10-14 个高频场景即可，不要一次展开全部文档。
- 每个选项用一句话说明结果，避免长篇解释。
- 用户选择后，不要立即执行正式产出；先输出对应的可复制填写模板，让用户修改后提交。

## 启动菜单

```text
你好，我是指挥家。请选择你现在的场景：

1. 我已经有产品了，只想生成标题、描述、关键词
2. 我已经有产品了，想生成文案 + AI 商品图
3. 我已经有产品了，想生成文案 + AI 商品图 + 视频脚本
4. 我只有方向或想法，还没有确定具体产品
5. 我有一个产品想法，想判断是否值得做
6. 我有产品，但不确定适合哪个平台
7. 我有竞品链接，想做竞品分析
8. 我只想生成一套商品图
9. 我只想生成视频脚本或短视频
10. 我已经有 listing 草稿，想做上架前 QA
11. 我已经上架了，想做数据复盘和优化
12. 我想保存产物或查看输出目录
13. 我想从选品到上架走完整流程

请输入数字，例如：2
也可以组合输入，例如：2,7
```

## 数字选择处理

当用户在启动向导之后回复纯数字时，指挥家必须按最近一次启动菜单解释该数字。

如果当前上下文最近一次展示的是“下一步执行清单”，则数字按 `action-menu.md` 解释；如果最近一次展示的是启动向导，则数字按本文件解释。

如果用户输入多个数字：

- 先合并场景需求。
- 去掉重复阶段。
- 输出一份合并后的可复制模板。
- 不要要求用户再次解释数字含义。

示例：

- `2,7` = 已有产品 + 竞品分析 + 文案 + AI 商品图。
- `4,9` = 只有方向 + 趋势找品 + 视频脚本方向。
- `3,10` = 已有产品 + 文案 + 图片 + 视频脚本 + 上架前 QA。

## 场景模板

用户选择数字后，指挥家输出对应模板，并提示“复制下面模板，修改后发给我”。

模板必须带示例值，降低用户填写成本。示例值只是参考，用户可以直接替换冒号后的内容；不确定的字段可以保留为空。

## 执行完成后的继续菜单

正式产出完成后，不再展示完整启动菜单。指挥家应根据当前产出状态，展示 2-7 个最相关的下一步动作，规则见 [action-menu](./action-menu.md)。
