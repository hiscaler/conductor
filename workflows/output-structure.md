# 输出目录和文件命名规范

## 使用原则

输出目录只使用两个定位层级：平台市场和 Listing 标识。商品名称、类目、SPU、包含内容等可变信息写入商品资料，不再作为目录层级，避免同一商品因为改名或类目调整产生多个目录。

固定结构：

```text
output/{平台}-{市场}/{Listing标识}/
```

示例：

```text
output/Temu-US/MUG0110RD/
```

平台和市场由系统根据当前任务自动生成，不要求用户额外填写目录名称。

## 平台市场标识

- 格式为 `{平台展示名}-{市场代码}`，例如 `Temu-US`、`Amazon-JP`、`Etsy-GB`。
- 平台使用统一展示名，例如 `Temu`、`Amazon`、`TikTok-Shop`。
- 市场已确定时优先使用常用两位国家或地区代码，例如美国 `US`、日本 `JP`、英国 `GB`、德国 `DE`。
- 平台或市场暂未确定时使用 `待定`，例如 `待定-US`、`Temu-待定`；信息确认后，新产物进入正式目录，不把待定目录当作正式交付目录。
- 同一商品面向不同平台或市场时必须分开保存，不能混用文案、平台属性、图片规格或视频规格。

## Listing 标识

Listing 标识由系统自动生成，不要求用户手工命名。

生成优先级：

1. 单个已匹配 SKU 且销售数量为 1：使用商品主表中的标准 SKU，例如 `MUG0110RD`。
2. 销售数量大于 1 或包含多个 SKU：按标准 SKU 排序并合并重复数量，生成 `组合-{SKU}x{数量}+{SKU}x{数量}`。
3. 没有 SKU 的具体商品：使用 `未建档-{简短商品名}`。
4. 尚无具体商品的找品任务：使用 `找品-{简短方向}`。
5. 只有竞品、关键词或榜单的调研任务：使用 `调研-{简短关键词}`。

示例：

```text
output/Temu-US/MUG0110RD/
output/Temu-US/组合-MUG0110WHx6/
output/Temu-US/组合-BOX000001x1+MUG0110RDx2/
output/Temu-US/未建档-红色定制马克杯/
output/待定-US/找品-宠物出行用品/
```

规则：

- SKU 匹配沿用商品资料库规则：去除首尾空格、忽略英文字母大小写，命中后使用主表标准写法。
- 组合标识必须与本轮实际售卖内容一致；即使只有一个 SKU，销售数量大于 1 时也必须写入数量。数量变化视为不同 Listing。
- 标识中的文件系统非法字符替换为短横线；连续空格压缩为一个短横线。
- 商品改名、标题优化或类目调整不得改变已确定的 SKU 或组合 Listing 目录。

## Listing 目录

同一个 Listing 的所有产物放在同一目录：

```text
output/{平台}-{市场}/{Listing标识}/
  商品资料.md
  文案/
  图片/
  视频/
  竞品/
  供应链/
  上架/
  合规/
  利润/
  测试/
```

`商品资料.md` 至少记录商品名称、标准类目、SPU、标准 SKU 或 SKU 组合、销售数量、目标平台、目标市场和当前确认事实。目录定位依赖 Listing 标识，不依赖商品名称。

## 文件命名

面向用户查看的文件和卖家侧栏目使用中文。只有可直接复制到目标平台、面向买家或用于搜索及广告投放的最终文案值使用目标市场语言。

推荐命名：

```text
商品资料.md
文案/文案资产.md
文案/关键词清单.md
图片/01-主图.png
图片/02-到手内容图.png
图片/03-规格图.png
图片/图片验收报告.md
图片/套图脚本.md
视频/01-主视频.mp4
视频/视频脚本.md
视频/视频验收报告.md
竞品/竞品分析.md
供应链/供应商候选表.md
供应链/供应链风险报告.md
上架/上架包.md
上架/上架前QA报告.md
合规/合规风险报告.md
利润/利润测算.md
测试/测试计划.md
```

具体图片数量和图型由平台、品类和产品类型规则决定，不在目录规范中固定。

## 版本和覆盖

- 同名文件已存在时，默认创建 `-v2`、`-v3` 等新版本，不得静默覆盖。
- 同一次生产中的文案、图片、视频和验收报告必须继续使用同一个 Listing 目录。
- 历史目录不自动迁移或删除；需要整理时应先建立旧路径与新 Listing 标识的映射，再单独执行迁移。

## 动作输出路径

所有下一步动作必须遵守本规范，例如：

```text
output/Temu-US/MUG0110RD/文案/文案资产.md
output/Temu-US/MUG0110RD/图片/01-主图.png
output/Temu-US/MUG0110RD/图片/图片验收报告.md
```
