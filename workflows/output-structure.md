# 输出目录和文件命名规范

## 使用原则

所有围绕同一个产品产生的文案、图片、QA 报告、合规报告、竞品分析和上架包，都必须放在同一个产品目录下，方便用户查看和交付。

目录结构固定为：

```text
output/{目标平台}/{产品类目}/{产品名称}/
```

示例：

```text
output/Temu/宠物用品/可折叠宠物饮水杯/
```

## 子目录

产品目录下按资产类型分组：

```text
output/{目标平台}/{产品类目}/{产品名称}/
  文案/
  图片/
  竞品/
  上架/
  合规/
  利润/
  测试/
```

## 文件命名

面向用户查看的文件必须使用中文命名。

推荐命名：

```text
文案/文案资产.md
文案/关键词清单.md
图片/01-主图.png
图片/02-到手内容图.png
图片/03-容量规格图.png
图片/04-折叠收纳图.png
图片/05-挂扣便携图.png
图片/06-使用场景图.png
图片/07-对比图.png
图片/图片验收报告.md
图片/套图脚本.md
竞品/竞品分析.md
上架/上架包.md
上架/上架前QA报告.md
合规/合规风险报告.md
利润/利润测算.md
测试/测试计划.md
```

## 路径生成规则

- 目标平台使用用户输入的展示名，例如 `Temu`、`Amazon`、`TikTok Shop`。
- 产品类目使用用户输入的中文类目，例如 `宠物用品`。
- 产品名称使用用户输入的中文产品名，例如 `可折叠宠物饮水杯`。
- 不要默认转换成英文 slug，除非文件系统或外部平台不支持中文。
- 如果产品名称包含文件系统不允许的字符，替换为中文顿号或短横线。
- 如果同名文件已存在，默认创建带版本号的新文件，例如 `文案资产-v2.md`，不要覆盖。

## 动作输出路径

所有 action-menu 中的输出位置必须遵守本规范。

示例：

```text
output/Temu/宠物用品/可折叠宠物饮水杯/文案/文案资产.md
output/Temu/宠物用品/可折叠宠物饮水杯/图片/01-主图.png
output/Temu/宠物用品/可折叠宠物饮水杯/图片/图片验收报告.md
```
