# 通用电商语义与创意规则

本文件沉淀跨平台可复用的方法论。它只负责帮助 Agent 理解买家意图、选择表达框架和组织图片/视频叙事；最终标题结构、要点描述、关键词位置、图片数量、视频比例和合规要求仍以目标平台规则为准。

## 使用边界

- 本规则适用于 Amazon、Temu、Shopify、Etsy、TikTok Shop、eBay、AliExpress、Walmart Marketplace 及未覆盖平台。
- 不得把 Amazon 的标题、bullet、A+、后台关键词或 Rufus 规则套用到其他平台。
- 通用语义和创意模型只能增强表达，不得覆盖平台硬性要求。
- 只有已确认事实可以进入最终买家文案和图片内文案；竞品、评论和趋势只能形成建议或待验证机会。
- 不能用创意模型放大未确认功能、认证、材质、尺寸、适用人群、效果或授权素材。
- 创意模型名称只用于卖家侧规划，不得把 `FAB`、`AIDA`、`PAS` 等框架名称写进买家文案。
- 商品图片只能直接确认可见的外观、颜色、数量和结构，不能单独证明材质、精确尺寸、认证、安全性、性能或兼容性。
- 定制示例、故事人物、场景道具和视觉参考默认排除未经授权的品牌、商标、角色、名人、艺术作品和摄影作品。

## 语义意图映射

生成商品示例、文案、图片脚本和视频脚本前，先把商品资料映射为买家意图。无法确认的内容写“待确认”或只作为“市场建议”。

| 维度 | 需要回答的问题 | 适用产出 |
| --- | --- | --- |
| 本体分类 | 产品是什么，属于哪个细分品类，上位品类是什么 | 标题、类目、关键词 |
| 销售单位/组合关系 | 实际卖的是单件、对装、多件装、套装还是混合组合，包含什么、数量多少 | 标题、主图、包装图、价格、平台属性 |
| 变体与定制边界 | 当前 listing 对应哪个 SKU，可选颜色/尺寸/款式是什么，哪些部位和内容可以定制 | 标题、变体属性、定制说明、图片脚本 |
| 核心功能 | 产品直接完成什么动作或解决什么问题 | 要点描述、卖点图、视频动作 |
| 能力属性 | 哪些参数、结构或材质带来可感知能力 | 要点描述、规格图、详情页 |
| 最终目的 | 用户买它是为了达成什么结果 | 标题、场景图、广告文案 |
| 使用地点 | 在哪里使用：家庭、办公室、户外、车内、旅行、厨房等 | 场景图、视频分镜、关键词 |
| 使用时间 | 适合什么季节、节日、时机或日常频率 | 节日策略、礼赠图、广告活动 |
| 活动事件 | 服务什么活动：遛狗、露营、生日、婚礼、返校、搬家等 | 场景词、图片脚本、视频故事 |
| 目标受众 | 商品明确面向谁 | 标题、要点描述、受众场景图 |
| 实际使用者 | 谁会真实使用，购买者和使用者是否不同 | 礼品文案、视频人物设定 |
| 身份标签 | 买家或使用者的身份：父母、宠物主人、学生、通勤者等 | 情绪文案、广告受众 |
| 身体部位 | 是否作用于身体部位、肤质、尺码或佩戴位置 | 服装、美妆、健康、运动类 |
| 兴趣偏好 | 买家长期关注什么生活方式或审美 | Shopify、Etsy、A+、视频风格 |
| 即时欲望 | 买家此刻想要什么体验或结果 | 首屏钩子、短视频开头 |
| 搭配使用 | 通常和什么配件、场景物或其他商品一起使用 | 套装机会、关联销售、图片道具 |
| 角色替代 | 商品可作为礼物、装饰、备品、旅行装、入门套装等角色 | 礼赠图、组合策略、标题修饰 |
| 搜索/任务意图 | 买家是在找具体商品、某项属性、问题解决方案、适用场景还是礼物 | 标题、搜索关键词、广告词、内容入口 |
| 决策阻力 | 哪些尺寸、兼容、材质、护理、定制、物流或售后问题会阻止购买 | FAQ、要点描述、规格图、信任内容 |
| 证据锚点 | 哪条已确认资料能够支撑当前卖点和购买理由 | 文案事实链、图片内文案、视频演示、QA |

### 事实等级

每个语义意图都必须标注来源等级，避免把市场推测写成商品事实。

| 等级 | 可进入买家文案 | 来源 |
| --- | --- | --- |
| 已确认事实 | 可以 | 用户明确确认的一般商品资料、商品资料库、已核对的供应商资料、图片中可直接观察的外观事实、已验证官方/平台页面 |
| 合理推测 | 不直接进入最终文案 | 商品名称、品类常识、图片可见线索推断出的可能用途 |
| 市场建议 | 不直接进入最终文案 | 竞品页面、评论痛点、趋势数据、热销榜表达 |
| 待确认 | 不进入最终文案 | 无证据的尺寸、材质、认证、适用人群、功能、性能、售后、授权 |

补充边界：

- 合理推测和市场建议可以用于卖家侧候选创意、调研方向和待验证机会，但不能在买家可见文字或画面中呈现为商品已经具备的事实。
- 用户或供应商提供的认证、食品接触安全、医疗/健康效果、性能数字、兼容型号等高风险声明，必须有对应证据后才能作为最终买家声明。
- 场景可以表达已确认用途，但不能借画面暗示未确认性能。例如普通杯子可以出现在饮用场景中，未确认前不能用蒸汽留存、冰块时长或密封倒置画面暗示保温、保冷或防漏。

### 语义到产物映射

- 商品标题：优先覆盖本体分类、销售单位、核心属性、主要用途、目标受众或关键场景；不要把所有意图全部塞进标题。
- 要点描述：每条只服务一个主要意图，使用“已确认属性 -> 可感知能力 -> 买家利益”的链路。
- 长描述：补充使用地点、活动事件、搭配使用、礼赠角色和护理/使用说明。
- 搜索关键词：拆分为核心品类词、已确认功能词、场景词、受众词、时间/节日词、搭配词和同义词；不得加入不适用人群、虚假兼容、竞品品牌或侵权词。
- 后台关键词：优先放标题和前台文案未覆盖但相关的同义词、上位词、场景词和受众词；不得放竞品品牌或侵权词。
- 主图和包装图：必须和销售单位、SKU、组合关系及实际到手内容一致。
- 变体和定制说明：必须明确当前 SKU 与可选项的边界，不能把其他变体、未包含配件或未确认定制方式混入当前商品。
- 图片脚本：把抽象利益转成可见画面，例如“便携”要展示携带动作、尺寸对比或收纳状态。
- 视频脚本：用即时欲望和活动事件设计前三秒钩子，用核心功能和使用地点设计中段动作，用结果或情绪设计结尾。

## 创意模型选择

Agent 根据产品类型、购买动机和平台心智选择表达模型，不要求用户填写。

| 模型 | 适合场景 | 常见用法 | 注意事项 |
| --- | --- | --- | --- |
| FAB | 功能型、工具、3C、户外、规格驱动商品 | 属性 -> 优势 -> 买家利益 | 每个利益必须由已确认属性支撑 |
| PAS | 痛点明显、清洁、收纳、宠物、日常问题解决 | 痛点 -> 困扰 -> 解决方案 | 不制造恐惧，不夸大问题 |
| AIDA | 新奇、冲动购买、短视频和促销场景 | 注意 -> 兴趣 -> 欲望 -> 行动 | 行动提示要克制，避免平台敏感促销词 |
| BAB | 改善生活品质、高客单价、家居和效率类 | 现状 -> 理想状态 -> 产品桥梁 | 不承诺无法证明的结果 |
| 4P | Shopify、独立站、长详情页、A+ 模块 | 画面/愿景 -> 有边界的价值主张 -> 证据 -> 行动 | 证据只能来自已确认事实，不制造虚假稀缺 |
| SSS | 礼品、宠物、母婴、定制类、情绪价值商品 | 主角 -> 故事 -> 解决方案 | 人物和故事要贴合目标市场 |
| Quest | 利基市场、专业性强、需要教育的商品 | 筛选 -> 共情 -> 教育 -> 激发 -> 转化 | 不把竞品缺点写成无证攻击 |

### 平台推荐组合

| 平台 | 推荐模型 | 适用方式 |
| --- | --- | --- |
| Amazon | FAB + 语义意图映射 | 强化搜索相关性、事实密度和购买收益 |
| Temu | FAB + AIDA | 快速说明规格、用途、到手内容、SKU 差异和选择理由 |
| Shopify | 4P + PAS | 做首屏价值主张、痛点解释、证据和 FAQ |
| Etsy | SSS + FAB | 连接礼品/定制情绪，同时写清材质、尺寸和制作信息 |
| TikTok Shop | AIDA + SSS | 前三秒钩子、场景化口播、人物动机和行动提示 |
| eBay | FAB | 强调型号、状态、参数、配件和物流边界 |
| AliExpress | FAB + AIDA | 强调规格、SKU 差异、价格和物流预期 |
| Walmart Marketplace | FAB | 零售化表达，重事实、规格和可信度 |

### 模型使用约束

- 一个产物只选 1-2 个主模型，不要把所有模型同时套用。
- 平台推荐组合只是起点；最终按商品类型、购买动机、内容载体、证据强度和合规风险选择，不能只按平台机械套用。
- 主图和规格图优先事实表达，不使用复杂故事模型。
- 短视频和广告短文案可以更强钩子，但不能制造未证实的痛点或效果。
- 高风险类目优先 FAB 和事实说明，弱化夸张情绪表达。
- Before/After 对比不作为默认独立模型；只有差异可观察、可复现并有证据时才可使用，医疗、美妆、身体变化、清洁效果和性能结果不得用生成画面伪造前后对比。

## 创意方向选择

创意方向选择是正式内容生产前的轻量交互，用于让用户在多个可行表达方案中选一个。具体交互规则维护在 [创意方向选择流程](../workflows/creative-direction-selection.md)。是否展示选择菜单和是否形成创意策略是两件事：跳过菜单不代表正式产出可以缺少创意策略。

### 何时需要

- 用户要求文案 + 图片、文案 + 视频、完整上架资产或广告内容，且需要统一多个内容载体的表达。
- 商品有多个购买动机，需要在自用、礼赠、场景解决、价格感、品牌故事之间收敛方向。
- 商品属于定制、礼品、宠物、母婴、家居、服饰、美妆、节日等更依赖场景和情绪表达的类目。
- 平台内容形态更需要创意统一，例如 Shopify、Etsy、TikTok Shop、Amazon A+ 或短视频投放。

### 何时跳过

- 本轮只做供应链、利润、合规、QA、保存或查看产物。
- 商品是强规格驱动标准品，已确认卖点单一，且平台表达路径明确。
- 用户已经给出明确创意主题、广告故事或视觉方向时，跳过菜单并沿用该方向。

### 免交互处理

- 用户要求“直接输出”“按默认输出”或“跳过创意选择”时，不展示菜单；Agent 仍应基于已确认事实自动形成默认创意策略，并继续正式产出。
- 用户已经提供明确方向时，不展示菜单；Agent 将用户方向整理成可执行创意方案，并记录“沿用用户方向”。
- 本轮只有供应链、利润、合规、QA、保存或查看任务时，创意策略写“不适用”。
- 强规格标准品不展示菜单时，使用事实优先的默认策略，不得把“未展示菜单”写成“没有创意方向”。

### 方向生成要求

- 每次输出 3-5 个可执行方向，使用纯数字。
- 候选方向必须针对当前商品、平台和市场生成，不能只输出“日常刚需型”“礼赠型”等可套用任何商品的空泛标签。
- 每个方向至少展示：具体方向名称、目标市场语言的创意主题或钩子、适合人群、购买动机、证据锚点、与其他方向的关键差异、推荐理由和主要风险。
- 文案、图片、视频的完整执行主线在用户选择后生成；菜单只需简要说明本轮实际请求的内容载体如何落地，避免重复展示大段方案。
- 用户只回复数字或“自动选择”；选择后直接生成可执行创意方案并继续原任务。
- 可执行创意方案必须服务本轮实际请求的文案、图片或视频，不能只是一句概念口号；未请求的内容载体写“本轮未执行”，不强制虚构完整方案。
- 买家可见钩子和主题使用目标市场语言；卖家侧解释和风险边界使用中文。
- 一个正式版本只能有一个主创意方向；其他候选方向可保留为 A/B 测试备选，但不得把互相冲突的主题混入同一套文案、图片或视频。

### 自动选择规则

自动选择按以下维度判断：平台匹配度、事实与证据强度、目标市场相关性、差异化程度、资产可执行性和合规风险。证据不足或风险较高时，优先选择事实更强、画面更容易真实执行的方向；不得因为故事更吸引人就牺牲事实边界。

## 买家问题预判

所有平台都应预判买家可能关心的问题；Amazon 可进一步转为 Q&A、A+ 或 Rufus 友好内容，其他平台按自身页面结构吸收。

只预判会实质影响当前商品购买决策的问题，不为凑数量生成通用 FAQ。优先检查：

- 实际售卖数量、组合关系、SKU 和变体是否一致。
- 材质是否安全、是否适合目标使用场景。
- 尺寸、容量、重量、数量和到手内容是否清楚。
- 是否适合目标人群或使用者。
- 是否支持定制，定制位置、内容和制作周期是什么。
- 如何使用、安装、清洁、护理或保存。
- 是否兼容某型号、配件、场景或已有商品。
- 包装、礼赠、物流、退换和售后边界。
- 哪些功能尚未确认，不能写进最终文案。

### 问题到内容位置

| 问题类型 | 优先承载位置 |
| --- | --- |
| 销售数量、组合关系、SKU/变体 | 标题、主图、包装图、平台属性 |
| 尺寸、容量、重量、数量 | 规格图、要点描述、详情页参数 |
| 材质、安全、认证状态 | 要点描述、信任图、Q&A、合规说明 |
| 定制方式、位置、周期 | 定制操作示意图、描述、FAQ |
| 清洁、护理、安装、使用方法 | 详情页、步骤图、视频演示 |
| 适用人群和场景 | 标题、场景图、视频人物设定 |
| 包装清单和到手内容 | 包装图、到手内容图、上架字段 |
| 退换、售后和物流 | 平台详情页、FAQ、上架包 |

回答买家问题时，不能用“通常”“一般”“应该可以”替代证据；证据不足时写“待确认”并放在卖家侧待确认项。

## 图片和视频叙事

图片和视频应覆盖“看清产品、理解用途、确认规格、相信到手内容、形成购买理由”五类信息，但具体数量和顺序由平台图片/视频规则决定。所有画面必须沿用已选择或默认形成的主创意方向，同时保持 SKU、数量、定制效果和事实声明一致。定制类套图必须先以已验收主图建立唯一的定制母版，后续画面以主图为参考锚点；除明确标注的定制选项/效果示例图或真实多 SKU/多变体对比图外，不得改变定制文字、图案、颜色、布局、位置和相对比例。

通用视觉角色：

- 主图：清楚展示实际售卖商品和销售数量。
- 场景图：展示真实使用地点、动作和目标人群。
- 功能图：把核心功能转成可见动作或结果。
- 规格图：展示尺寸、容量、材质、数量、包装清单等已确认事实。
- 细节图：用放大镜、局部圆窗、箭头或标注解释已有商品图或资料能够确认的关键结构，不得生成原资料中不存在的细节。
- 礼赠/情绪图：展示购买动机、关系表达、定制效果或节日场景。
- 信任图：只使用已经核验的包装、售后、认证、材质或品牌信息；认证标志、检测报告、评价和评分必须使用真实获授权素材，不得由 AI 生成。
- 对比图：只比较已确认参数或可观察差异，不攻击竞品。

### AI 视觉证据边界

- AI 生成图片是内容表达和场景模拟，不是商品事实、做工、材质、认证、测试结果或用户评价的证据。
- AI 放大细节必须以真实商品图或已确认结构资料为依据；缺少依据时保留完整商品外观并把该细节标记为“待补实拍”，不得猜测纹理、接口、内层或工艺。
- 认证标志、检测报告、专利标识、评价星级、销量徽章和平台背书不得通过生成工具伪造。
- 需要证明做工、材质纹理、包装清单或实际效果时，优先使用实拍、供应商原图或已核验文件；只有文字资料时，生成图只能标记为“示意”，不能在验收中作为已验证证据。

### 视觉脚本生成顺序

1. 先确定平台必备图型和技术规格。
2. 再把语义意图分配到每张图，避免多张图重复表达同一卖点。
3. 主图解决“是什么”和“到手数量”；规格图解决“是否适合”；场景图解决“怎么用”；细节图解释“已确认的结构和细节是什么”；礼赠图解决“为什么适合送礼或表达关系”。只有存在真实有效的节日、活动或促销依据时，才表达“为什么现在买”。
4. 视频先确定购买动机和前三秒钩子，再设计动作和镜头连续性。
5. 平台允许添加文字的图片和视频，文案必须短句化并使用目标市场语言；主图禁字、促销词、价格和版式要求仍以平台规则为准。

## 平台适配要求

- Amazon：可使用语义意图映射强化标题、5 条 bullet points、后台关键词、A+、Q&A 和图片脚本。
- Temu：只吸收“买家快速理解”的部分，重点转成规格卖点、到手内容、SKU/变体差异、尺寸图和高信息密度辅图；动态价格或未确认价格不得写入图片。
- Shopify：重点用于首屏价值主张、详情页模块、FAQ、品牌故事和广告落地页。
- Etsy：重点用于定制说明、礼品场景、风格词、材质尺寸和制作周期。
- TikTok Shop：重点用于前三秒钩子、口播场景、直播话术和移动端封面。
- eBay、AliExpress、Walmart：重点用于参数完整性、使用场景、SKU 差异、包装清单和信任信息。
- 未覆盖平台：先确认平台属于搜索型 marketplace、内容/社交电商、品牌独立站、定制/手作平台还是参数/二手交易平台，再读取该平台当前 listing 字段和硬性规则；不得仅凭相似平台直接套用。

## 目标市场本地化

- 创意主题、场景、人物关系、节日、用语和视觉道具必须符合目标市场，不做逐字翻译。
- 尺寸、容量、日期、货币和语言格式按目标市场习惯表达；平台或项目已有双单位规则时同时保留。
- 节日或事件创意必须结合当前日期、生产周期、物流和营销准备时间，过期或来不及执行的方向不得进入候选菜单。
- 无法确认当地文化含义、敏感表达或受众适配时，选择中性方向并标记待本地化复核。
