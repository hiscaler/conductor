# 平台视频技术规格

## 使用原则

视频技术规格包括比例、分辨率、时长、帧率、文件格式、字幕安全区、封面图和音频要求。

规格分为两层：

1. 推荐生产规格：用于脚本、拍摄和 AI 生成。
2. 平台上传规则：以上架后台最新官方要求为准，上传前必须复核。

## 通用生产标准

- 竖屏短视频优先：`1080 x 1920 px`，比例 `9:16`。
- 商品页通用视频：`1920 x 1080 px`，比例 `16:9`，或 `1080 x 1080 px`，比例 `1:1`。
- 帧率：`24-30 fps`。
- 文件格式：优先 `MP4`。
- 编码：H.264/H.265，以上传平台支持为准。
- 字幕安全区：重要文字避开上下 `12%` 和左右 `8%`。
- 无声可理解：移动端视频必须在无声播放时仍能理解核心信息。
- 音频强制：最终视频必须包含可听音轨和目标市场语言口播；建议采样率 `48 kHz`，音频编码优先 `AAC`。
- 情绪表演：口播必须根据广告故事明确情绪基调、语速、重音词、停顿位置、音量变化和句尾语气。不得使用全程同一语速、同一音高、同一音量的机械朗读。
- 自然度：允许自然呼吸、轻微语气词和符合目标市场表达习惯的缩略说法，但不得影响清晰度或编造产品事实。
- 文案分工：字幕与口播语义一致即可，不要求逐字一致。字幕应短而清楚，口播应补充情绪和上下文，禁止照读参数表或逐条念出卖点。
- 字幕强制：目标市场语言字幕必须烧录进画面并与口播同步；外挂字幕文件不能替代烧录字幕。
- 混音要求：口播清晰居前，背景音乐和音效不得遮盖人声；不得有爆音、削波、明显底噪、音画不同步或突兀断音。
- 版权要求：音乐、口播和音效必须可商用或由生成工具原创，不使用未授权歌曲、影视音频或受保护声音素材。
- 首帧/封面：必须清楚展示产品和核心用途。
- 禁止：水印、平台 logo、竞品品牌、未授权音乐、未确认认证标识。

## Amazon

- 推荐比例：`16:9` 或 `1:1`。
- 推荐分辨率：`1920 x 1080 px` 或 `1080 x 1080 px`。
- 推荐时长：15-45 秒。
- 文件格式：MP4。
- 重点：清晰展示产品和使用方式。

## Temu

- 推荐比例：`1:1` 或 `9:16`。
- 推荐分辨率：`1080 x 1080 px` 或 `1080 x 1920 px`。
- 推荐时长：8-20 秒。
- 文件格式：MP4。
- 重点：移动端快速理解，字幕简短，节奏快。

## Shopify

- 推荐比例：按页面位置决定，常用 `16:9`、`9:16`、`1:1`。
- 推荐分辨率：`1920 x 1080 px`、`1080 x 1920 px` 或 `1080 x 1080 px`。
- 推荐时长：15-60 秒。
- 文件格式：MP4 或 WebM。
- 重点：质量和加载速度平衡。

## Etsy

- 推荐分辨率：`1080 x 1080 px` 或 `1080 x 1350 px`。
- 推荐时长：5-15 秒。
- 文件格式：MP4。
- 重点：真实质感和细节。
