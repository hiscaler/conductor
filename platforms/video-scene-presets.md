# 视频预设场景库

## 使用原则

本文件用于让 `visual-production-agent` 根据目标平台、产品类型、核心卖点、素材状态和视频目的自动选择可执行的视频结构。

- 预设场景只规定视频结构和动作类型，不得编造产品功能、规格、包装、配件、认证或使用效果。
- 默认自动选择 1 个主预设；需要视频组时可选择 2-3 个互补预设，但每条视频必须使用独立脚本、独立提示词和独立文件。
- 默认不要求用户提供实拍视频或供应商视频。系统应根据目标平台、产品品类、产品事实、核心卖点和商品参考图片自动生成连续动态镜头。
- 有商品参考图片或已生成商品图时，将其作为商品身份锚点，生成真实动作、使用过程、人物互动和连续镜头；禁止直接制作静态图片轮播。
- 没有商品参考图片但产品外观、结构、颜色、规格和使用方式描述充分时，可根据描述自动生成动态视频，并标记素材来源为“产品资料生成”。
- 只有在商品外观或关键结构信息不足、无法保证事实一致时，才降级为概念视频，并标注“需商品图片或实物资料校准”；不得因为缺少实拍视频而阻塞生成。
- 每条最终视频必须包含真实动态镜头、目标市场语言口播、烧录字幕以及可商用或生成式音频；缺少任一项均为“未完成”。

## 自动选择顺序

```text
目标平台
→ 产品品类与产品类型
→ 购买动机与视频目的
→ 选择广告故事
→ 选择镜头风格
→ 选择产品动作
→ 商品图片与产品资料状态
→ 组合主预设与备选预设
→ 用产品事实填充故事
→ 生成连续广告分镜
→ 生成口播、字幕、音乐和音效
→ 合成并验收
```

选择优先级：

1. 用户明确指定的场景。
2. 平台最适配的场景。
3. 能由商品参考图或已确认产品资料稳定生成的场景。
4. 能解释核心购买理由的场景。
5. 风险最低且无需编造事实的场景。

## 三层广告故事引擎

视频不得只按品类替换商品。每条视频必须分别选择“广告故事”“镜头风格”和“产品动作”，再组合成适合该商品的独立广告方案。

### 第一层：广告故事

| 广告故事 | 适用购买动机 | 基本叙事 |
| --- | --- | --- |
| 个性表达 | 定制、风格、身份表达 | 发现商品 → 创建个性内容 → 成品揭示 → 日常拥有 → 行动提示 |
| 情感送礼 | 节日、感谢、纪念、关系表达 | 选择礼物 → 定制或包装 → 递送 → 收礼反应 → 行动提示 |
| 问题解决 | 明确痛点、功能需求 | 问题发生 → 商品介入 → 使用过程 → 结果改善 → 行动提示 |
| 自用升级 | 日常用品、体验改善 | 普通日常 → 发现升级点 → 使用商品 → 更舒适的日常 → 行动提示 |
| 便捷体验 | 便携、折叠、安装、收纳 | 出发或准备 → 快速使用 → 场景切换 → 轻松收起 → 行动提示 |
| 开箱发现 | 套装、配件、到手内容 | 包装出现 → 打开 → 逐件发现 → 组合使用 → 行动提示 |
| 场景陪伴 | 多场景、多地点、多用途 | 主场景 → 第二场景 → 第三场景 → 产品特写 → 行动提示 |
| 使用前后 | 可验证的状态变化 | 使用前状态 → 操作过程 → 使用后状态 → 事实解释 → 行动提示 |

选择规则：优先从产品定位、目标人群、核心场景和已确认卖点判断购买动机。无法确认购买动机时，默认选择“自用升级”；不得为了套用故事编造痛点、效果或人物关系。

### 第二层：镜头风格

| 镜头风格 | 适用平台与商品 | 表达要求 |
| --- | --- | --- |
| 生活方式广告 | Shopify、Etsy、Temu；家居、礼品、日用品 | 自然光、真实环境、克制字幕、人物与商品自然互动 |
| UGC 真人分享 | TikTok Shop、Shopify；适合手持演示的商品 | 手机拍摄感、自然口语、真实手势和口型、不过度表演 |
| 产品电影感广告 | Shopify、Amazon；外观和质感重要的商品 | 稳定运镜、材质特写、光影层次、少量精准文案 |
| 快节奏商品演示 | Temu、TikTok Shop、AliExpress | 前 3 秒强动作、短镜头、信息密度高、动作匹配转场 |
| 温馨礼品故事 | Etsy、Shopify、Temu；礼品和定制商品 | 温暖光线、包装与递送、真实情绪反应、柔和音乐 |
| 清晰功能讲解 | Amazon、Walmart、eBay、AliExpress | 使用步骤、尺寸、配件和结果清楚，少广告腔 |

### 第三层：产品动作

每条视频必须从产品自身可真实发生的动作中选择，不得只移动镜头：

- 拿起、放下、旋转、翻面或靠近观察。
- 打开、关闭、展开、折叠、安装、连接或拆卸。
- 倒入、取出、装入、佩戴、悬挂、携带或收纳。
- 输入定制内容、确认设计、揭示最终定制效果。
- 打开包装、逐件取出、组合摆放或开始使用。
- 人物与商品产生符合物理逻辑的真实互动。

不能由已确认商品结构支持的动作必须删除。仅有镜头推拉、平移、缩放、光效或文字动画不算产品动作。

## 广告叙事节奏

默认采用以下节奏，但必须根据平台时长压缩或扩展：

| 阶段 | 建议时间 | 作用 |
| --- | --- | --- |
| 动态钩子 | 0-3 秒 | 商品立即入镜，通过动作、情绪或问题吸引注意 |
| 故事建立 | 3-7 秒 | 交代人物动机、使用场景或购买原因 |
| 商品体验 | 7-14 秒 | 展示真实产品动作、使用过程和核心卖点 |
| 结果与情绪 | 14-18 秒 | 展示使用结果、拥有感或情感回报 |
| 行动提示 | 最后 2-3 秒 | 完整商品特写，加简短目标市场语言行动文案 |

行动提示必须放在故事和产品体验之后，不能整条视频持续催促购买。不得默认使用虚假折扣、倒计时、库存紧张或价格承诺。

## 自然衔接规则

- 优先使用动作匹配转场：点击按钮接商品旋转、打开包装接取出商品、拿起商品接实际使用。
- 可使用视线匹配、方向匹配、遮挡转场和相似形状转场。
- 避免每个镜头都淡入淡出、闪白、缩放或套用同一种模板转场。
- 前一镜头的结束状态必须成为后一镜头的合理起始状态。
- 每条视频最多使用 1-2 种转场语言，保持统一广告风格。
- 人物动作需要有准备、执行和结束阶段，不能突然跳变。

## 广告自然度要求

- 人物必须有明确但克制的动机，例如自用、解决问题、准备礼物或改善日常体验。
- 加入真实生活微动作和环境反馈，例如输入文字、拆包装纸、放下陶瓷杯、整理配件或自然注视商品。
- 一个镜头只表达一个主要信息，字幕每屏建议 3-7 个词。
- 核心卖点通常控制在 2-3 个，避免把整份 listing 塞进视频。
- 口播应像自然广告旁白或真实使用分享，不照读参数表。
- 背景音乐随故事变化但保持克制，动作音效只强化真实触感。

## 情绪口播导演规则

每条视频必须先生成“口播导演说明”，再生成最终口播。导演说明至少包含：角色身份、情绪基调、情绪变化、语速、重音词、停顿、句尾语气和与画面的同步节点。

| 广告故事 | 推荐情绪轨迹 | 口播表现 |
| --- | --- | --- |
| 个性表达 | 好奇 → 期待 → 满足 | 开头轻快自然，定制揭示时略微提升情绪，结尾自信邀请 |
| 情感送礼 | 温暖 → 期待 → 感动 | 语速稍慢，关键关系词轻柔重读，收礼时保留短暂停顿 |
| 问题解决 | 共鸣 → 清楚 → 轻松 | 痛点段自然共情，演示段简洁明确，结果段语气放松 |
| 自用升级 | 平静 → 发现 → 愉悦 | 像分享日常好物，避免强推销腔，结尾轻松自然 |
| 便捷体验 | 利落 → 惊喜 → 确定 | 节奏稍快，动作节点短句表达，关键便利点重读 |
| 开箱发现 | 期待 → 逐步惊喜 → 满足 | 开箱前留悬念，逐件展示时有层次，避免每件同一语气 |
| 场景陪伴 | 自然 → 丰富 → 安心 | 语气随场景轻微变化，整体保持统一、亲切和稳定 |
| 使用前后 | 共鸣 → 专注 → 释然 | 前段指出真实问题，中段解释动作，后段表达可验证结果 |

口播生成要求：

- 先写“口播意图”，再写口播台词；每句话必须说明希望观众感受到什么。
- 使用适合目标市场的自然口语，不写成产品说明书。
- 一句话只承担一个主要表达目的，允许停顿和长短句变化。
- 对产品名称、核心收益和行动提示设置重音，但每句最多 1-2 个重音点。
- 动作发生时优先用短句，情绪或场景建立时可用稍长句。
- 行动提示应像自然邀请，不使用持续高压、喊叫或夸张促销口吻。
- 生成音频时必须把情绪标签、语速、停顿和重音指令传给语音生成工具；不能只提交纯台词文本。

以下情况判定为机械口播并必须重做：

- 全程语速、音高和音量几乎不变。
- 逐字朗读烧录字幕或逐条朗读卖点、尺寸和参数。
- 每句话使用相同节奏和相同句尾语气。
- 情绪与画面不符，例如温馨送礼画面使用促销喊麦语气。
- 停顿位置不自然、重音落在虚词上、数字和单位读法生硬。
- 口播听起来像系统通知、说明书或导航语音。

## 通用镜头要求

- 前 3 秒必须展示商品和动态钩子，不能只出现标题、logo 或静态图片。
- 每条视频至少包含 3 个有效动态分镜，其中至少 1 个商品使用动作或人手互动镜头。
- 每个分镜必须写明：起始状态、主体动作、镜头运动、结束状态、持续时间、烧录字幕、口播、音效和连续性锚点。
- 同一商品的颜色、结构、尺寸比例、配件数量和定制内容必须在所有镜头中保持一致。
- 禁止连续两个分镜仅展示静态商品图；转场、推拉、平移、缩放和光效不能代替真实动作。
- 默认使用硬切或动作匹配转场，避免过多模板化特效。

## 预设 1：三秒钩子＋使用演示

- 适用平台：Temu、TikTok Shop、AliExpress，也可用于其他平台的移动端短视频。
- 适用品类：功能明确、能够快速演示的商品。
- 推荐时长：8-20 秒。
- 推荐结构：动态钩子 → 使用动作 → 核心卖点 → 商品收尾。
- 必备动作：前 3 秒内由手拿起、展开、安装、开启或实际使用商品。
- 字幕结构：购买结果或用途钩子 → 1-2 个事实卖点 → 简短行动提示。
- 音频：目标市场语言快节奏口播；轻快背景音乐；动作节点配合轻微音效。
- 禁止事项：只有促销文字、虚假效果、静态套图轮播。

## 预设 2：开箱＋到手内容

- 适用平台：Amazon、Temu、eBay、AliExpress、Walmart Marketplace。
- 适用品类：套装、多配件、包装或到手内容影响购买决策的商品。
- 推荐时长：10-30 秒。
- 推荐结构：包装入镜 → 打开包装 → 逐件取出 → 摆放完整清单 → 商品特写。
- 必备动作：真实开盒、取出商品或配件、按实际数量摆放。
- 字幕结构：包装名称 → 包含数量 → 配件名称 → 到手内容总结。
- 音频：清晰说明到手内容的口播；轻背景音乐；开盒和摆放音效。
- 禁止事项：编造包装形式、配件或赠品，数量与 SKU 不一致。

## 预设 3：痛点＋解决方案

- 适用平台：TikTok Shop、Shopify、Temu、Amazon。
- 适用品类：有明确使用痛点和可验证解决方式的功能型商品。
- 推荐时长：12-30 秒。
- 推荐结构：真实痛点动作 → 商品介入 → 使用演示 → 结果场景 → 行动提示。
- 必备动作：痛点和解决过程必须在连续动作中呈现。
- 字幕结构：痛点问句 → 产品作用 → 已确认卖点 → 使用场景。
- 音频：口语化口播；问题段音乐克制，解决段节奏提升；关键动作音效。
- 禁止事项：夸张前后对比、虚构效果、医疗或绝对化承诺。

## 预设 4：定制过程＋最终效果

- 适用平台：Temu、Etsy、Shopify、TikTok Shop。
- 适用品类：定制文字、图片、图案或雕刻商品。
- 推荐时长：10-25 秒。
- 推荐结构：输入或选择定制内容 → 定制区域示意 → 成品动态揭示 → 场景或礼品展示。
- 必备动作：镜头中必须出现已完成定制的最终商品；定制图案真实贴合商品表面。
- 字幕结构：添加内容类型 → 定制位置 → 最终效果 → 示例内容提示。
- 音频：温暖或轻快口播；简洁音乐；确认、揭示或包装动作音效。
- 连续性锚点：定制文字、图片、颜色、位置和商品结构全程一致。
- 禁止事项：以空白基底作为最终效果，使用 `YOUR NAME`、`YOUR TEXT`、`CUSTOM PHOTO` 作为成品图案，使用未授权 IP。

## 预设 5：多场景使用

- 适用平台：Shopify、Amazon、Temu、Walmart Marketplace。
- 适用品类：适用地点或人群较多的日用品、家居、宠物和户外商品。
- 推荐时长：15-30 秒。
- 推荐结构：主场景使用 → 第二场景自然衔接 → 第三场景或便携展示 → 商品收尾。
- 必备动作：每个场景都必须出现真实使用动作，不能只更换静态背景。
- 字幕结构：场景名称 → 该场景下的真实购买理由。
- 音频：统一口播音色和音乐风格；场景转换使用轻微环境音或动作音效。
- 禁止事项：与产品不符的场景、人物比例错误、跨镜头商品外观变化。

## 预设 6：尺寸规格＋细节展示

- 适用平台：Amazon、Temu、AliExpress、eBay、Walmart Marketplace。
- 适用品类：尺寸、接口、结构、配件或细节影响购买决策的商品。
- 推荐时长：10-25 秒。
- 推荐结构：完整商品旋转 → 尺寸测量动作 → 关键细节近景 → 规格总结。
- 必备动作：实物旋转、标尺测量、部件开合或细节指示。
- 字幕结构：`cm` 与 `inch` 双单位尺寸 → 已确认规格 → 购买前确认提示。
- 音频：说明型口播；低干扰背景音乐；测量或部件动作音效。
- 禁止事项：编造尺寸、只用静态尺寸图、细节与完整商品不一致。

## 预设 7：礼品场景＋情绪价值

- 适用平台：Etsy、Shopify、Temu。
- 适用品类：定制礼品、节日商品、纪念品和情感型商品。
- 推荐时长：10-25 秒。
- 推荐结构：包装准备 → 递出礼物 → 收礼互动 → 成品特写。
- 必备动作：包装、递送、打开或真实互动动作。
- 字幕结构：送礼对象或场合 → 个性化价值 → 简短购买理由。
- 音频：温暖自然的目标市场语言口播；柔和可商用音乐；包装和揭示音效。
- 禁止事项：过度表演、未授权人物肖像、虚构包装或节日承诺。

## 预设 8：UGC 真人演示

- 适用平台：TikTok Shop、Shopify，也可用于社媒广告。
- 适用品类：适合手持展示、快速演示或体验分享的商品。
- 推荐时长：10-30 秒。
- 推荐结构：真人钩子 → 手持展示 → 使用演示 → 个人化购买理由 → 行动提示。
- 必备动作：人物必须真实持有或使用商品，口型、手势和商品动作自然。
- 字幕结构：口语化短句，与口播逐句同步。
- 音频：自然真人感口播；低音量背景音乐；必要动作音效。
- 禁止事项：伪造专家身份、虚构体验、使用未授权达人形象、口型与声音明显不同步。

| eBay | 开箱＋到手内容 | 尺寸规格＋细节展示 |
| AliExpress | 三秒钩子＋使用演示 | 尺寸规格＋细节展示、开箱＋到手内容 |
| Walmart Marketplace | 开箱＋到手内容 | 尺寸规格＋细节展示、多场景使用 |

定制类商品优先覆盖“定制过程＋最终效果”，即使平台默认预设不同，也必须在主视频或视频组中体现最终定制效果。

## 品类自动映射

平台默认映射决定视频节奏，品类映射用于修正具体动作和备选预设：

| 产品品类 | 优先预设 | 推荐动作 |
| --- | --- | --- |
| 定制礼品、马克杯、服装、饰品 | 定制过程＋最终效果 | 输入定制内容、成品揭示、旋转展示、包装送礼 |
| 厨房、家居、收纳 | 痛点＋解决方案 | 取放、展开、收纳、整理、真实使用 |
| 宠物用品 | 三秒钩子＋使用演示 | 主人拿取、宠物互动、户外或居家使用 |
| 户外、旅行、便携用品 | 多场景使用 | 携带、展开、安装、使用、收起 |
| 电子配件、工具 | 三秒钩子＋使用演示 | 连接、安装、开启、操作、结果展示 |
| 美妆、个护 | UGC 真人演示 | 手持展示、使用步骤、质地或细节展示；不得编造功效 |
| 服饰、箱包、饰品 | 多场景使用 | 穿戴、开合、容量展示、细节转动 |
| 多配件、套装商品 | 开箱＋到手内容 | 打开包装、逐件取出、按真实数量摆放 |
| 尺寸敏感或结构复杂商品 | 尺寸规格＋细节展示 | 商品旋转、标尺测量、部件开合、接口特写 |

自动选择时先取得平台默认主预设，再用产品品类、定制属性和核心卖点校正。若两者冲突，以不编造事实、能清楚演示商品用途且适合平台转化为优先。

## 自动验收门禁

只有全部满足以下条件，视频才可标记为“已完成”：

- 已记录所用预设名称和选择理由。
- 前 3 秒存在产品动态钩子。
- 至少 3 个有效动态分镜。
- 至少 1 个商品使用动作或人手互动镜头。
- 不是静态图片轮播。
- 商品外观、SKU、配件和定制内容跨镜头一致。
- 有目标市场语言口播。
- 有与口播和画面同步的烧录字幕。
- 背景音乐和音效可商用且不遮盖口播。
- 无声观看仍可通过画面和字幕理解核心信息。
- 没有编造功能、规格、认证、包装或配件。

任一门禁不通过时，必须写“未完成”，列出失败项并提供重新生成缺失镜头、补配音、补字幕或重新合成的下一步动作。
