# 平台图片技术规格

## 使用原则

图片技术规格包括尺寸、比例、分辨率、文件格式、清晰度、压缩质量和文字安全区。

这些规格分为两层：

1. 推荐生产规格：用于设计和 AI 生成，保证图片质量足够高。
2. 平台上传规则：以上架后台的最新官方要求为准，上传前必须复核。

如果推荐规格和平台后台要求冲突，以平台后台要求为准。

## 通用生产标准

- 优先输出正方形商品图：`2000 x 2000 px`。
- 最低建议边长：`1500 px`。
- 不建议低于：`1000 x 1000 px`。
- 文件格式：优先 `PNG` 用于生成和中间稿，最终上传可按平台压缩为 `JPG` 或 `WEBP`。
- 色彩：`sRGB`。
- 清晰度：产品主体边缘清楚，不能有明显 AI 伪影、糊边、错字、变形配件。
- 压缩：最终 JPG 建议质量 `85-95`，避免明显压缩块。
- 主体占比：主图中产品建议占画面 `75%-85%`，具体以平台规则为准。
- 安全区：重要文字和产品关键部位距离边缘至少 `8%` 画布宽度。
- 移动端可读：图中文字在手机预览中仍可识别，不使用过细字体。
- 文字原则：按图片类型控制文字密度，不是一律少字。主图通常少字或无字，卖点图、规格图、尺寸图、步骤图、对比图应使用简洁文字说明核心功能、规格参数、到手内容或购买理由。
- 文字质量：图中文字必须短句化、可读、可校对；AI 生成后需要检查错字、乱码、虚构认证、虚构参数和误导性表达。
- 尺寸单位：尺寸/规格图必须同时标注 `cm` 和 `inch`；容量、重量、温度等参数按目标市场习惯补充对应单位。未提供真实尺寸时，不得编造换算。
- 细节图构图：细节图应保持完整商品主体可见，通过放大镜、局部圆窗、连线、箭头或标注框展示细节，不得只用简单裁切放大代替细节说明。
- 定制品外观：定制类商品图片必须展示定制内容在商品表面的实际效果；主图、包装图、定制区域说明图和定制操作示意图都必须以最终定制商品为主体，不得只展示空白基底或空白定制区域。未提供具体定制内容时，只能用中性占位示例并标注为示例。

## Amazon

- 推荐商品图：`2000 x 2000 px` 正方形。
- 最低生产建议：不低于 `1600 x 1600 px`。
- 主图比例：正方形优先。
- 背景：主图纯白背景。
- 文件格式：JPG 或 PNG。
- 质量重点：支持放大查看，产品边缘清晰，白底干净。
- 注意：主图是否允许配件、道具、文字，以类目和后台规则为准。

## Temu

- 推荐商品图：`2000 x 2000 px` 正方形。
- 最低生产建议：不低于 `1200 x 1200 px`。
- 主图比例：正方形优先，移动端浏览友好。
- 背景：浅色或白底优先，主图要一眼看清商品和到手内容。
- 文件格式：JPG 或 PNG。
- 质量重点：高信息密度但不拥挤，文字在移动端可读。
- 注意：规格、数量、SKU 图必须和实际售卖内容一致。

## Shopify

- 推荐商品图：`2000 x 2000 px` 或 `2400 x 3000 px`。
- 推荐详情页横图：`2400 x 1350 px` 或 `1920 x 1080 px`。
- 推荐首屏/广告图：按页面设计输出，可用 `1920 x 1080 px`、`2160 x 2700 px` 或 `2400 x 3000 px`。
- 文件格式：JPG、PNG、WEBP。
- 质量重点：品牌一致性、加载速度和清晰度平衡。
- 注意：独立站可以更灵活，但要控制文件体积，避免拖慢页面加载。

## Etsy

- 推荐商品图：`2000 x 2000 px` 或 `3000 x 2400 px`。
- 主图比例：正方形或横向轻宽幅均可，但移动端裁切后主体必须完整。
- 文件格式：JPG 或 PNG。
- 质量重点：真实质感、细节、比例、定制选项清晰。
- 注意：主图应避免过多文字，优先展示产品审美和真实质感。

## TikTok Shop

- 推荐商品图：`2000 x 2000 px` 正方形。
- 推荐封面/短视频封面：`1080 x 1920 px` 竖图。
- 推荐短视频分镜图：`1080 x 1920 px`。
- 文件格式：JPG 或 PNG；视频素材按平台后台要求另行确认。
- 质量重点：移动端一眼看懂，竖屏裁切安全。
- 注意：重要产品和文字放在中间安全区，避免被按钮、价格或标题遮挡。

## eBay

- 推荐商品图：`1600 x 1600 px` 或 `2000 x 2000 px`。
- 主图比例：正方形优先。
- 文件格式：JPG 或 PNG。
- 质量重点：真实、清楚、可判断成色和配件。
- 注意：二手、翻新、瑕疵类商品必须清晰展示真实状态。

## AliExpress

- 推荐商品图：`2000 x 2000 px` 正方形。
- 推荐详情页长图模块：宽度 `1200-1500 px`，高度按内容分段。
- 文件格式：JPG 或 PNG。
- 质量重点：SKU、尺寸、使用步骤和包装清单清楚。
- 注意：多 SKU 图片必须避免让买家误以为包含全部款式。

## Walmart Marketplace

- 推荐商品图：`2000 x 2000 px` 正方形。
- 最低生产建议：不低于 `1500 x 1500 px`。
- 背景：主图白底或干净浅色背景，零售化表达。
- 文件格式：JPG 或 PNG。
- 质量重点：清晰、克制、属性和图片一致。
- 注意：避免过度广告化和不明确的认证表达。

## 未覆盖平台处理

如果目标平台未覆盖，先输出图片技术规格调研清单：

- 主图尺寸
- 图片比例
- 最小分辨率
- 最大文件大小
- 支持格式
- 是否允许透明背景
- 是否允许图中文字
- 是否有移动端裁切安全区
- 是否有类目特殊规则

规则未确认前，默认按 `2000 x 2000 px` 正方形生成商品图，并标注“需上传前确认平台图片技术规格”。
