# 平台画像与适配规则

## 使用原则

所有平台统一执行语言边界：给卖家查看的平台策略、分析、字段说明、风险、建议和验收内容必须使用中文；只有直接用于目标平台、面向买家或用于搜索及广告投放的最终文案值使用目标市场语言。该规则适用于 Amazon、Temu、Shopify、Etsy、TikTok Shop、eBay、AliExpress、Walmart Marketplace 及未覆盖平台。

同一产品在不同平台必须采用不同内容策略。agent 需要先判断目标平台，再决定标题结构、卖点表达、图片结构、关键词策略和合规检查重点。

如果用户同时选择多个平台，应分别输出平台版本，不要只输出一份通用内容。

套图规则单独维护在 [image-set-rules](./image-set-rules.md)。平台画像只描述图片方向，具体图片数量、主图约束、辅图结构和验收标准以套图规则为准。

通用语义意图、创意模型、买家问题预判和跨平台视觉叙事维护在 [commerce-semantic-creative-rules](./commerce-semantic-creative-rules.md)。这些规则可用于所有平台，但不能覆盖本文件中的平台专用写法。

## 商品示例属性规则

用户提供最小商品信息后，系统生成的可复制商品示例必须根据“目标平台 + 商品类目”动态补充上架重要属性，不能只生成营销卖点，也不能使用一套固定属性适配所有商品。

- 通用候选属性：产品类目、产品类型、销售单位/组合形态、包含内容、销售数量、是否同款/混色/混款、规格尺寸、材质、颜色/款式、数量、包装清单、SKU/变体、使用或护理信息、认证状态。
- 销售单位必须单独判断：单件、对装、多件装、套装、混色装、混款装、礼盒装、旅行装、入门套装、替换装和补充装不能只当普通关键词；它们会影响标题、主图、包装清单、平台属性和价格判断。
- 多件装必须归一化不同写法：例如 `3个装`、`3 个装`、`三个装`、`３个装`、`3 件装`、`三件装`、`3-pack`、`pack of 3`、`set of 3` 都表示销售数量为 3 的多件装；其他数字同理。
- “N 件套”“N件套”等歧义表达必须写“待确认”，并提示确认是多个同款商品还是主商品加配件；未确认前不得生成误导性主图或按多件装测算价格。
- 定制类候选属性：定制内容、定制位置、可定制范围、印刷/制作方式、可提交文件类型、生产周期和定制示例。
- 类目属性按商品变化：马克杯关注容量、高度、杯口直径、底径、含把手宽度；服装关注尺码、版型和尺寸表；电子配件关注接口、兼容型号和供电参数；宠物用品关注适用对象、尺寸和容量。
- 平台已确认要求必须写入示例；需要登录、后台未展示或证据不足时写“待后台确认”。
- 商品名称和图片无法证明的精确数值、材质、认证、性能和包装信息写“待确认”，不得猜测。
- 美国市场的长度尺寸默认同时保留 `cm` 与 `inch`，容量按适用品类同时保留 `oz` 与 `ml`。

## 要点描述平台适配

`templates/production-output.md` 统一使用“要点描述”作为栏目名，但该栏目内容必须按目标平台改写，不得把 Amazon 的五点 bullet 结构套用到所有平台。

| 平台 | 要点描述写法 | 数量和结构 | 注意事项 |
| --- | --- | --- | --- |
| Amazon | 5 条 bullet points | 5 条，每条先写买家收益，再写功能证据 | 避免无证认证、医疗或绝对化承诺 |
| Temu | 规格卖点 / 短卖点 | 3-6 条短句，突出规格、数量、用途、到手内容和价格感 | 不写品牌故事，不堆长段落 |
| Shopify | 产品页卖点模块 | 3-5 个模块，可包含痛点、场景、信任点和 FAQ 引导 | 不必写成 5 条 bullet，服务页面转化 |
| Etsy | 商品亮点 / 定制与礼品说明 | 4-6 条，突出材质、尺寸、定制方式、制作周期、送礼场景 | 不能暗示未确认手作、版权或授权 |
| TikTok Shop | 短卖点 / 直播话术要点 | 3-5 条口语化短句，适合短视频和直播解释 | 避免夸张结果、前后对比误导 |
| eBay | 关键参数 / 状态说明 | 3-6 条，突出型号、规格、成色、配件、物流退换边界 | 二手或翻新商品必须说明真实状态 |
| AliExpress | 规格说明 / SKU 差异 / 使用要点 | 4-8 条，突出规格、SKU、包装清单、使用方法、物流预期 | 避免 SKU 图片和文字不一致 |
| Walmart Marketplace | Key Features | 3-6 条，清晰、克制、零售化 | 用事实和规格支撑，不写过度广告腔 |

未覆盖平台先根据平台调研清单确认 listing 字段。如果平台没有类似要点字段，则在“要点描述”中输出适合该平台的商品摘要模块，并标注“需平台字段确认”。

## Amazon

- 核心逻辑：搜索驱动 + 转化率驱动。
- 用户心智：目标明确，重视评价、参数、价格、配送和可信度。
- 标题重点：关键词覆盖、核心规格、适用场景、关键属性。
- 文案重点：要点描述按 Amazon bullet points 结构输出，先讲购买收益，再讲功能证据。
- 语义重点：结合核心大词、长尾意图词、场景词、受众词、搭配词和后台泛词；优先把产品本体、功能、目的、场景、受众、时间、搭配和礼品角色映射清楚。
- Q&A 重点：围绕材质、安全、尺寸、清洁、兼容、适用人群、包装和售后预判买家问题；无法证实的答案写“待确认”，不得进入最终买家文案。
- 图片重点：白底主图合规，辅图要解释卖点、尺寸、场景、对比和包装清单。
- A+ 重点：可规划竞品对比、Q&A、品牌故事和使用场景模块，但只能使用已确认事实。
- 竞品重点：BSR、价格带、评价数量、差评痛点、QA 高频问题。
- 风险点：夸大功效、医疗承诺、认证造假、兼容性误导、侵权词。
- 输出必备：标题、要点描述（Amazon 按 5 条 bullet points 输出）、长描述、搜索词、A+ 页面模块建议、7 张图脚本。

### Amazon 专用执行规则

Amazon 生产前必须先输出简短的语义意图摘要，至少覆盖：本体分类、核心功能、能力属性、最终目的、使用地点、活动事件、目标受众、实际使用者、搭配使用和礼品/替代角色。无法确认的内容只写入“待确认”或“市场建议”，不得进入最终买家文案。

标题规则：

- 前 80 个英文字符优先放核心品类词、关键属性、核心规格或主要转化点。
- 标题必须兼顾 A9 核心关键词和语义意图词，但不能堆砌同义词。
- 定制类商品可在标题前段加入 `Personalized`、`Custom`、`Custom Name`、`Custom Photo` 等已确认定制词。
- 不写未确认认证、材质等级、适用年龄、兼容型号、功效、保修或品牌授权。

要点描述规则：

- 当前项目约定 Amazon 输出 5 条 bullet points，不采用外部文档中的 6 条结构。
- 每条建议结构为：场景/买家利益 + 深度说明 + 已确认事实。
- 5 条尽量分别覆盖：核心用途、关键规格/材质、使用场景/受众、到手内容/兼容边界、礼品/售后/护理等信任信息。
- 每条都要包含可抓取的具体事实或属性，避免只写 `premium`、`high quality`、`perfect` 等空泛形容词。

关键词规则：

- 前台关键词覆盖核心品类词、主要属性、核心用途和目标受众。
- 后台关键词补充未在标题和要点中覆盖的同义词、上位类目词、场景词、活动词、搭配词和长尾意图词。
- 禁止使用竞品品牌、侵权 IP、无法证明的认证词和重复堆砌。

Q&A 和 A+ 规则：

- Q&A 默认预判 5-8 个问题，优先覆盖材质安全、尺寸容量、清洁护理、适用人群、定制方式、包装清单、物流售后和兼容边界。
- A+ 页面建议至少包含：核心价值模块、场景模块、规格/参数模块、对比模块、Q&A 或信任模块。
- 对比模块只能比较已确认参数、到手内容、使用场景或服务边界，不得攻击竞品。

Amazon 图片脚本建议：

- 主图：白底、产品清晰、符合实际售卖数量。
- 场景图：展示目标受众和使用地点。
- 功能/痛点图：把核心功能转成可见动作或已确认结果。
- 参数图：展示尺寸、容量、材质、数量、包装清单等事实。
- 受众/礼品图：展示购买者与使用者关系，适合定制和礼品类。
- 信任图：仅展示已确认认证、包装、售后或品牌信息。

## Temu

- 核心逻辑：低价转化 + 高频曝光 + 强促销。
- 用户心智：价格敏感，快速比较，重视“看起来划算”。
- 标题重点：简短清晰，突出品类、数量、规格和直接用途。
- 文案重点：少写品牌故事，多写规格、用途、套装、适用场景。
- 图片重点：信息密度高，快速展示到手内容、尺寸、数量、使用效果。
- 竞品重点：同款价格、主图点击点、套装组合、评论痛点。
- 风险点：图片夸张、规格不清、到手内容误导、低价导致预期落差。
- 输出必备：短标题、规格卖点、促销短文案、价格锚点建议、6-8 张图脚本。

## Shopify

- 核心逻辑：品牌信任 + 页面转化 + 流量承接。
- 用户心智：需要被教育和说服，重视品牌感、故事、保障和体验。
- 标题重点：可读性优先，不必堆关键词。
- 文案重点：首屏价值主张、痛点解决、使用场景、信任背书、FAQ。
- 图片重点：生活方式图、品牌质感图、使用前后逻辑、细节图。
- 竞品重点：独立站页面结构、offer、bundle、UGC、评论组件、订阅或加购策略。
- 风险点：页面过度营销、证据不足、素材风格割裂、承诺过强。
- 输出必备：产品页首屏文案、详情页模块、广告落地页文案、FAQ、8-10 张图脚本。

## Etsy

- 核心逻辑：搜索发现 + 手作/个性化/礼品场景。
- 用户心智：寻找独特、定制、礼物、有审美的商品。
- 标题重点：关键词覆盖 + 风格词 + 场景词 + 礼品词。
- 文案重点：材质、尺寸、定制方式、制作周期、送礼场景、护理方式。
- 图片重点：真实质感、细节、比例、包装、个性化选项、礼品场景。
- 竞品重点：标签词、价格、定制选项、评价中的送礼反馈。
- 风险点：版权/IP 侵权、手作属性误导、定制说明不清。
- 输出必备：Etsy 标题、13 个 tags、描述、个性化说明、10 张图脚本。

## TikTok Shop

- 核心逻辑：内容种草 + 短视频转化 + 达人分发。
- 用户心智：被场景和演示打动，重视即时效果和价格刺激。
- 标题重点：直接说明用途、结果和适用人群。
- 文案重点：短、口语化、强场景，适合直播间和短视频口播。
- 图片重点：封面图要有强识别，辅图要适合移动端快速理解。
- 竞品重点：爆款视频钩子、达人话术、评论问题、价格和赠品。
- 风险点：夸张效果、前后对比误导、平台敏感词、素材版权。
- 输出必备：商品标题、短卖点、直播话术、短视频脚本、封面图和商品图脚本。

## eBay

- 核心逻辑：搜索 + 价格 + 稀缺性/库存状态。
- 用户心智：比较价格、成色、物流、卖家信誉。
- 标题重点：关键词、型号、规格、状态、适配范围。
- 文案重点：参数清晰、成色说明、物流退换、兼容性边界。
- 图片重点：真实产品图、细节、瑕疵说明、包装和配件。
- 竞品重点：成交价、运费、成色、卖家评分、同型号 listing。
- 风险点：型号误导、成色误导、品牌侵权、兼容性过度承诺。
- 输出必备：eBay 标题、Item specifics、描述、物流说明、图片清单。

## AliExpress

- 核心逻辑：搜索 + 价格 + 跨境物流 + 多 SKU。
- 用户心智：重视价格、SKU 选择、物流时效、买家秀。
- 标题重点：关键词覆盖、多规格、多用途。
- 文案重点：规格表、SKU 差异、使用说明、物流和售后预期。
- 图片重点：SKU 对比、尺寸、场景、安装/使用步骤、包装清单。
- 竞品重点：同款 SKU、价格梯度、物流选择、评价图片。
- 风险点：规格不一致、SKU 图片误导、物流承诺过强。
- 输出必备：标题、详情页模块、SKU 命名、关键词、8-10 张图脚本。

## Walmart Marketplace

- 核心逻辑：搜索 + 零售可信度 + 标准化属性。
- 用户心智：重视实用、价格、配送、退换和品牌可信度。
- 标题重点：品牌、品类、关键属性、规格。
- 文案重点：清晰、克制、零售化，不要过度广告腔。
- 图片重点：白底主图、功能图、尺寸图、场景图、包装清单。
- 竞品重点：价格、配送、评价、属性完整度。
- 风险点：属性不完整、过度营销、认证和安全声明不清。
- 输出必备：标题、Key Features、Description、Attributes、7 张图脚本。

## 未覆盖平台处理

如果目标平台不在以上列表，agent 必须先生成“平台调研清单”，包括：

- listing 字段
- 标题长度和格式
- 主图规则
- 图片数量和比例
- 关键词位置
- 禁用词和类目合规要求
- 竞品调研入口

在规则不明确时，只能输出通用草案，并标注“需平台规则确认”。
