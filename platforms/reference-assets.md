# SPU 共用参考资产规则

生产前读取当前 CSV 标准 SPU 对应的 `data/products/{SPU}/` 根层参考图及同名 JSON。SKU 实物图库仍位于 `data/products/{SPU}/{SKU}/`；SPU 共用参考不能替代 SKU 的 main 图或商品事实。当前马克杯目录为 `data/products/MUG/`，大小写沿用标准 SPU。

## 文件约定

- `ref-object-N.png/jpg`：真实实物参照；`ref-object-N.json`：名称、型号、尺寸及来源、核验状态、图片哈希。N 为正整数；辅助证据用 `ref-object-N-official.png`、`ref-object-N-dimensions.pdf`，不参加随机选择。
- `ref-custom-text-N.png`：仅文字定制模板；`ref-custom-image-N.png`：仅图片；`ref-custom-image-text-N.png`：图文。同名 JSON 记录适用 SPU、类型、版式、可用状态与哈希。
- 用户只需提供图片或来源，Agent 整理元数据。缺少 JSON 的图片先登记，不能凭文件名推断真实尺寸、定制类型或适用状态。
- 原始附件和历史资料用非候选文件名保留，不参与随机选择；图库入口为各 SPU 的 `reference-assets.md`。不得借用其他 SPU 的定制模板。

## 选择与一致性

- 用户明确指定优先；未指定时，从当前 SPU 适用且已核验的实物候选、匹配已确认定制类型的可用模板中分别随机选择一次。先核对实物是否适合当前商品的尺寸和使用目的，必要时明确传入适用候选。服务为不提供时不选定制模板。
- 执行 `node scripts/select-reference-assets.mjs <SPU> <图文|图|文|不提供> <当前生产目录> [ref-object-N.json] [ref-custom-text-N.json]`。生产目录必须是已分配的当前目录，不能为选择参考重新分配版本；脚本不创建 Listing 目录。
- 选择保存为该生产目录的 `参考资产选择.json`。同一套图所有需要参照物的图片使用同一实物，需要定制操作说明的图片使用同一模板类型与版式。未使用这些元素的图片不必额外添加。
- Temu 共享图案批次按图案组选择一次，同组全部 SKU 共用记录；其他模式按独立 Listing 选择。补图、修改、续做读取原记录，不重新随机。用户要求换参考时，明确更新选择并同步受影响的整套图片，不只更换一张。
- 脚本复用记录时核对 SPU、定制类型、图片及元数据哈希；元数据或素材变化须重新核对。缺少候选时记录缺失并暂停依赖该资产的图片，不自动借其他 SPU、未核实实物或随机生成道具补齐。
- 图片脚本、侧车和验收报告引用选定参考的文件、哈希与选择记录；最终逐张对照原图核实一致性。机器记录不能替代视觉验收。

## 实物证据

- 使用登记的真实源图约束外观，禁止自由生成品牌包装或平板外观。按 `image-technical-specs.md` 测量最终像素与真实尺寸并记录比例证据，标注 `Not Included`，不得暗示背书或成为商品印花。
- MUG 的 ref-object-1 为用户指定 Apple iPad Air (M4) 11 英寸正面图；官方规格、补充图和尺寸图纸另存。不能把两台重叠图的整体宽度当成单台宽度。
- ref-object-2/3 为美国版可口可乐 Original Taste / Pepsi 12 fl oz 罐；外观图已存，品牌对应罐体精确尺寸待核实。通用标准罐规格不能证明具体品牌包装尺寸，dimensions_verified=false 时不进入精确尺寸对比随机候选。
- 保存来源不等于取得公开再发布授权；保留既有来源与使用依据状态，使用前核对。商品资料仍以 CSV 为事实源。

## 定制模板的替换边界

- MUG 的 ref-custom-text-1 是用户确认的左步骤、右大杯版式；ref-custom-text-2 是顶部步骤、底部文字箭头的备用参考，两者均可在未指定时参加仅文字模板选择。
- 左步骤版保留 `1 ADD TEXT` 输入框与 `2 PREVIEW` 小杯；Your Text 占位示例只允许输入框和操作预览小图，右侧大杯文字区留白。顶部步骤版保留 ADD TEXT / PREVIEW 与 input your text 标签及曲线箭头，杯面不印占位字。
- 模板类型须匹配买家实际提交字段；“PREVIEW”表示操作效果示例，不得声称平台具备未经核实的实时预览能力。保留选定模板的杯口间距和宽裕文字留白，不拉长杯体。
- 所有出现商品的区域（含预览小图）同步替换为当前分配图案与 SKU 真实外观、颜色；固定图案完整呈现。仅作创意参考的图案不能擅自印到杯面。
- 其他品类使用自己的 SPU 模板和真实商品，不能沿用杯体。该留白只适用于用户指定的操作辅图；主图、包装图和最终效果图仍显示完成的定制内容，其他派生图遵守已验收母版。
- 原始 SKU 图、参考图均不被生成产物覆盖；成品仍保存到当前 Listing 目录。
