# 平台套图适配规则

## 使用原则

套图不能用一套固定模板适配所有平台。`visual-production-agent` 必须先读取目标平台，再按平台规则输出图片脚本。

如果同时输出多个平台，必须分别生成套图方案，不能把 Amazon 的白底主图逻辑、Shopify 的品牌场景图逻辑、TikTok Shop 的短视频封面逻辑混在一起。

图片尺寸、比例、格式和质量要求维护在 [image-technical-specs](./image-technical-specs.md)。套图脚本必须同时引用内容规则和技术规格。

每张图必须说明：

- 图片序号
- 图片类型
- 建议尺寸
- 建议比例
- 文件格式
- 质量要求
- 平台目的
- 核心信息
- 构图
- 主视觉元素
- 辅助元素
- 图中文字
- 图片生成提示词
- 禁止事项
- 验收标准

## 通用商品类型规则

- 普货：商品外观固定，套图重点是主图、到手内容、规格尺寸、核心卖点、使用场景和细节说明。
- 定制类：商品表面会定制文字、图片、logo 或图案，套图必须包含定制效果图或定制选项图，展示定制位置、可定制内容类型和最终效果。
- 定制类主图：必须展示已完成定制后的最终商品，定制内容应真实贴合商品表面；不能只展示空白商品、可定制区域框或位置示意。
- 定制类包装图：必须展示已定制商品与包装/到手内容的最终效果；如果包装也支持定制，包装表面也必须呈现定制内容。包装图不能只展示空白包装或可定制区域。
- 定制区域说明图：只能作为辅图解释定制范围、位置和输入内容类型，但画面主体也必须是已经放上定制内容的最终商品；箭头或标注框指向已呈现定制内容的区域，不能做成空白区域示意图，也不能替代主图、包装图或最终定制效果图。
- 定制内容缺失时：不得编造真实姓名、照片、品牌 logo 或 IP 图案。主图、包装图和定制效果图必须使用真实感中性样例内容，可以从 `Emma`、`Olivia`、`Mom`、`Best Dad`、`Coffee Time`、`Morning Brew`、通用风景照片、花朵图案、几何图案、宠物剪影中随机搭配，并标注为示例定制内容。随机搭配必须风格一致、贴合商品表面、符合目标市场审美，不能堆叠过多不相关元素。素材池只使用通用非侵权元素和原创抽象元素；品牌 logo、商标、影视/动漫/游戏角色、球队标志、名人肖像、真实人物照片、艺术家作品、摄影作品等可能受保护素材默认直接排除，不进入生成提示词，也不要求用户确认授权。`YOUR TEXT`、`YOUR NAME`、`CUSTOM PHOTO` 只能作为操作说明标签，不能作为最终商品表面的图案。
- 尺寸/规格图：必须同时标注 `cm` 和 `inch`；缺少真实尺寸时写“待确认”。
- 细节图：保持完整商品主体不变，用放大镜、局部圆窗、连线或标注框展示关键细节，不得只做简单裁切放大。

## Amazon

- 推荐数量：7-9 张商品图，另可补 A+ 页面模块图。
- 技术规格：商品图优先 `2000 x 2000 px` 正方形，主图白底，具体上传规则以上架后台为准。
- 主图：白底、只展示售卖商品本体和到手内容；不放促销文字、徽章、场景背景或夸张道具。
- 辅图结构：核心卖点图、场景图、尺寸图、功能拆解图、对比图、包装清单图、使用步骤图。
- 文案密度：中等，移动端可读，重点解释购买理由。
- 构图重点：真实、清晰、参数可信，降低购买不确定性。
- 风险：主图违规、认证夸大、尺寸误导、前后对比夸张、到手内容不一致。
- 验收：买家只看图片也能理解产品是什么、适合谁、有什么规格、怎么用、收到什么。

## Temu

- 推荐数量：6-8 张商品图。
- 技术规格：商品图优先 `2000 x 2000 px` 正方形，不低于 `1200 x 1200 px` 的生产质量，具体上传规则以上架后台为准。
- 主图：产品和套装内容要一眼清楚，强调规格、数量、用途和性价比。
- 辅图结构：到手清单图、尺寸规格图、多场景图、使用效果图、SKU 对比图、卖点集合图。定制类商品必须增加定制操作示意图。
- 定制操作示意图：画面主体必须是已完成定制的最终商品，用箭头、标注框或步骤标签指向已呈现定制内容的区域，说明可添加的内容类型，例如 `Add Your Name`、`Add Your Photo`、`Upload Image`。该图用于解释操作和定制区域，不能做成空白区域示意图，也不能替代最终定制主图或包装图。
- 定制类必备图片：最终定制主图、到手内容/包装图、定制操作示意图、尺寸规格图、细节放大图、生活场景图、定制效果示例图、卖点集合图。生成一套 Temu 定制类商品图时，默认以 8 张为完成标准；若只生成 4 张或缺少尺寸规格图、定制操作示意图、包装/到手内容图，必须判定为未完成。
- 文案密度：偏高，但必须短句化，适合快速扫读。
- 构图重点：高信息密度、强对比、低理解成本。
- 风险：规格不清、数量误导、效果夸张、图片看起来比实物高级过多。
- 验收：买家 3 秒内知道这是什么、多少钱值不值、包含几个、适合什么场景。

## Shopify

- 推荐数量：8-12 张，包含商品页图片、详情页模块图和广告落地页图。
- 技术规格：商品图可用 `2000 x 2000 px`，详情页横图可用 `2400 x 1350 px`，具体按页面设计和性能要求调整。
- 主图：可以更品牌化，不局限于白底，但首屏必须清楚展示产品。
- 辅图结构：生活方式图、痛点解决图、细节质感图、使用步骤图、信任背书图、FAQ 图、bundle 图。
- 文案密度：低到中等，强调品牌调性和页面节奏。
- 构图重点：品牌感、使用场景、信任建立、购买理由逐层递进。
- 风险：过度营销、图片风格割裂、承诺缺少证据、首屏看不清产品。
- 验收：图片能支撑独立站页面从兴趣、理解、信任到购买的转化路径。

## Etsy

- 推荐数量：10 张。
- 技术规格：商品图建议 `2000 x 2000 px` 或 `3000 x 2400 px`，移动端裁切后主体必须完整。
- 主图：真实质感强，突出成品美感、用途或礼品属性。
- 辅图结构：细节图、比例图、尺寸图、材质图、定制选项图、包装图、礼品场景图、使用/摆放图。
- 文案密度：低，图片以真实感和审美为主，必要信息用简短标注。
- 构图重点：手作感、个性化、礼品场景、材质和尺寸可信。
- 风险：侵犯 IP、手作属性误导、定制选项不清、尺寸比例误导。
- 验收：买家能判断质感、尺寸、定制方式、送礼效果和收到后的样子。

## TikTok Shop

- 推荐数量：5-8 张商品图，另配短视频封面和短视频分镜。
- 技术规格：商品图建议 `2000 x 2000 px`，短视频封面和分镜建议 `1080 x 1920 px` 竖图。
- 主图/封面：强识别、强场景、移动端一眼看懂。
- 辅图结构：痛点钩子图、演示图、使用前后逻辑图、卖点集合图、赠品/套装图、直播间说明图。
- 文案密度：中等偏高，但必须像短视频标题或直播话术一样直接。
- 构图重点：演示感、结果感、即时理解、适合竖屏裁切。
- 风险：效果夸张、前后对比误导、平台敏感词、素材版权、过度承诺。
- 验收：图片和封面能服务短视频点击、直播讲解和商品页快速转化。

## eBay

- 推荐数量：6-12 张，视产品状态和配件复杂度调整。
- 技术规格：商品图建议 `1600 x 1600 px` 或 `2000 x 2000 px`，真实状态清晰优先。
- 主图：真实产品图优先，清楚展示实物状态。
- 辅图结构：多角度图、细节图、瑕疵图、型号/标签图、配件清单图、包装图。
- 文案密度：低，信息主要放在标题和描述，图片要真实可信。
- 构图重点：成色、型号、配件、瑕疵边界和卖家可信度。
- 风险：成色误导、型号误导、隐藏瑕疵、配件不一致。
- 验收：买家能根据图片判断实物状态、型号、配件和潜在瑕疵。

## AliExpress

- 推荐数量：8-10 张，SKU 多时需要增加 SKU 对比图。
- 技术规格：商品图建议 `2000 x 2000 px`，详情页模块可按宽度 `1200-1500 px` 分段输出。
- 主图：展示产品本体和核心 SKU，视觉上清楚但不能误导数量和规格。
- 辅图结构：SKU 对比图、尺寸图、功能图、使用步骤图、场景图、包装清单图、物流/售后预期说明图。
- 文案密度：中到高，适合跨语言买家快速理解。
- 构图重点：规格清楚、多 SKU 差异明确、安装或使用步骤清晰。
- 风险：SKU 图片误导、尺寸误导、物流承诺过强、包装清单不清。
- 验收：买家能准确选择 SKU，并知道尺寸、使用方法和收到内容。

## Walmart Marketplace

- 推荐数量：7-9 张。
- 技术规格：商品图建议 `2000 x 2000 px` 正方形，不低于 `1500 x 1500 px` 的生产质量。
- 主图：白底、零售化、产品清晰，避免过度广告感。
- 辅图结构：功能图、尺寸图、场景图、包装清单图、安全或材质说明图、对比图。
- 文案密度：中低，表达克制、清楚、偏零售风格。
- 构图重点：实用、可信、规格完整、零售平台一致性。
- 风险：属性和图片不一致、认证表述不清、过度营销、主图不规范。
- 验收：图片符合零售平台的清晰度和可信度，能补足属性字段解释。

## 未覆盖平台处理

如果目标平台没有套图规则，先输出“图片规则调研清单”：

- 主图是否必须白底
- 图片数量上限
- 图片比例和尺寸
- 是否允许图中文字
- 是否允许促销信息
- 是否允许场景道具
- 是否需要视频或竖图
- 类目特殊限制

规则未确认前，只能输出通用图片脚本草案，并标注“需平台图片规则确认”。
